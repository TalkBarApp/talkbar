**ИИ-провайдер** — это место, где работает ИИ: этот компьютер, выбранный вами сервер Ollama или облачный сервис. **ИИ-модель** — это конкретный ИИ, который выполняет работу, например Qwen3.5 4B или Claude Sonnet. Один провайдер может предлагать много моделей. На этой странице описано, как подключать провайдеров и выбирать модели.

## Поддерживаемые провайдеры

| Тип провайдера | Провайдеры | Где работает |
| --- | --- | --- |
| **Встроенный ИИ** | Собственный ИИ TalkBar на устройстве | На этом компьютере. Есть всегда. Использует модели, скачанные в разделе [Локальные модели](/ai/local-models). |
| **Ollama** | Ollama на этом компьютере или на другом вашем компьютере | Там, где работает сервер Ollama |
| **Облачные провайдеры** (со своим API-ключом) | Anthropic, OpenAI, Google Gemini, Groq, xAI (Grok), DeepSeek, Cohere, Fireworks AI, Together AI, OpenRouter, AWS Bedrock | На серверах провайдера |
| **CLI-инструменты** | Claude Code CLI, Codex CLI, Agy CLI, Grok CLI, OpenCode CLI | Через собственный сервис инструмента, с аккаунтом, в который вы вошли |

Облачные провайдеры и CLI-инструменты используют ваш собственный аккаунт в этом сервисе, поэтому все расходы на использование — между вами и сервисом.

## Настройка ИИ

Проще всего подключить провайдера через окно **Настроить ИИ**. Откройте его из меню логотипа (**Настроить ИИ…**) или кнопкой **Настроить ИИ** в разделе **Настройки → ИИ-провайдеры**. Там показаны ваши **Провайдеры** и **Модели по умолчанию**, каждый шаг сопровождается подсказками, а в конце есть шаг **Проверить всё**. Ничего из этого не обязательно для начала работы, и окно можно открыть снова в любой момент.

Когда вы добавляете там провайдера, TalkBar спрашивает, как подключиться:

- **Локальный ИИ (Ollama)** — работает на этом компьютере. Приватно и бесплатно.
- **CLI-инструменты** — Claude Code, Codex, Agy, Grok CLI или OpenCode.
- **Используйте свой API-ключ** — Anthropic, OpenAI, Gemini, Groq и другие.

## Как добавить облачного провайдера с вашим API-ключом

1. Откройте **Настроить ИИ** и выберите **Используйте свой API-ключ** или нажмите **Добавить провайдера** в разделе **Настройки → ИИ-провайдеры → Провайдеры**.
2. Выберите провайдера.
3. Вставьте **API-ключ**. Поле **Адрес API (необязательно)** можно оставить пустым — тогда используется стандартный адрес провайдера.
4. Выберите модели, которые хотите использовать. TalkBar показывает модели провайдера и их возможности (**Текст**, **Изображения**, **Структурированный**). Чтобы использовать модель, которой нет в списке, нажмите **Добавить свою модель**; перед добавлением TalkBar отправит ей короткий проверочный запрос.

::screenshot{src="/screenshots/ai/add-provider-api-key.png" alt="Окно «Настроить ИИ» на шаге подключения к провайдеру: поле «API-ключ», необязательное поле адреса API и кнопка «Далее: выбор моделей»" caption="Подключение облачного провайдера"}
::

::callout{icon="i-heroicons-light-bulb" color="primary"}
**AWS Bedrock**: укажите свой регион AWS в адресе API (например, `bedrock-runtime.us-east-1.amazonaws.com`) и вставьте API-ключ Bedrock.
::

### Где хранится ваш API-ключ

TalkBar никогда не записывает API-ключ открытым текстом. Ключи, пароли и токены хранятся в зашифрованном виде в данных TalkBar на этом компьютере. Ключ, который их расшифровывает, хранится в системном хранилище ключей.

Чтобы сменить ключ, измените провайдера и вставьте новый ключ — он заменит старый.

Если системное хранилище потеряет ключ TalkBar или вы перенесёте данные TalkBar на другой компьютер, сохранённые ключи можно вернуть с помощью **кода восстановления**. Создайте его в разделе **Настройки → Данные и резервные копии** (см. [Резервное копирование и восстановление](/data/backup-and-restore)).

## Как подключить CLI-инструмент

Если у вас уже установлен ИИ-инструмент для командной строки и вы в нём вошли в аккаунт, TalkBar может работать через него.

1. Откройте **Настроить ИИ** и выберите **CLI-инструменты** или нажмите **Найти локальные CLI** при добавлении провайдера.
2. TalkBar ищет на компьютере Claude Code, Codex, Agy, Grok CLI и OpenCode и помечает каждый как **Обнаружен** или **Не обнаружен**.
3. Выберите нужный инструмент.

Установили инструмент позже? Нажмите **Повторить** в разделе **Локальные CLI-инструменты**.

Когда включён [приватный режим ИИ](/ai/private-ai-mode), CLI-инструменты никогда не используются.

## Как настроить Ollama

[Ollama](https://ollama.com) — бесплатное приложение, которое запускает ИИ-модели на вашем собственном оборудовании. TalkBar может использовать её на этом компьютере или на другом вашем компьютере.

::tabs
  ::div{label="На этом компьютере" icon="i-heroicons-computer-desktop"}
  1. Установите Ollama для вашей системы с сайта ollama.com/download.
  2. Скачайте модель в терминале. TalkBar рекомендует Gemma 4: `ollama pull gemma4:e4b`.
  3. В окне **Настроить ИИ** выберите **Локальный ИИ (Ollama)** → **Локальная установка** → **Найти Ollama**. TalkBar ищет Ollama по адресу `http://127.0.0.1:11434`.
  4. Выберите скачанные модели, чтобы зарегистрировать их в TalkBar.
  ::
  ::div{label="На другом компьютере" icon="i-heroicons-server"}
  1. Запустите Ollama на другом компьютере и разрешите входящие подключения (задайте там `OLLAMA_HOST=0.0.0.0`).
  2. В окне **Настроить ИИ** выберите **Локальный ИИ (Ollama)** → **Удалённый URL**.
  3. Введите адрес сервера вместе с портом и нажмите **Найти Ollama**.
  4. Выберите модели, которые нужно зарегистрировать.
  ::
::

::screenshot{src="/screenshots/ai/ollama-setup.png" alt="Окно «Настроить ИИ» на шаге Ollama с выбранной локальной установкой: найденная Ollama с версией и адресом и список скачанных моделей, где gemma4:e4b отмечена как рекомендуемая" caption="Настройка Ollama"}
::

### Локальный или удалённый?

[Приватный режим ИИ](/ai/private-ai-mode) использует только те серверы Ollama, которые TalkBar считает локальными:

- Ollama на этом компьютере, а также адреса в виде IP-адреса, имени, оканчивающегося на `.local`, или одиночного имени без точек автоматически считаются локальными.
- Для любого другого имени сервера TalkBar спрашивает **Считать «…» приватным локальным хостом?** Выберите **Считать локальным** или **Оставить удалённым**. Позже это можно изменить в настройках провайдера.
- Облачные модели Ollama (теги, оканчивающиеся на `cloud`) никогда не считаются локальными.

::callout{icon="i-heroicons-exclamation-triangle" color="amber"}
Сервер, который считается локальным, всё равно может быть другим компьютером, и он получает отправленный ему текст. Считайте локальными только те серверы, которыми управляете вы.
::

Если Ollama держит модель загруженной в видеокарте, встроенная модель может работать медленнее. Когда включён приватный режим ИИ, TalkBar может предупредить об этом и предложить выгрузить модель Ollama. Выгружать или нет — всегда решаете вы.

## Управление провайдерами и моделями

В разделе **Настройки → ИИ-провайдеры** четыре вкладки:

| Вкладка | Что там можно сделать |
| --- | --- |
| **ИИ-функции** | Выбрать модель по умолчанию и модели по функциям. См. [Как TalkBar использует ИИ](/ai/how-talkbar-uses-ai#как-выбирается-модель). |
| **Провайдеры** | Добавить, изменить, проверить, выключить или удалить провайдеров. |
| **Модели** | Посмотреть все модели, которые можно назначить, сгруппированные по провайдерам. **Добавить модель** регистрирует ещё одну модель подключённого провайдера. Здесь же показано, скачаны ли встроенные модели. |
| **Дополнительно** | Диагностика, язык ответов, свои инструкции, настройки запросов и ограничения локального ИИ. |

### Параметры модели

При добавлении или изменении модели можно задать:

- **Отображаемое имя** — как модель называется в TalkBar.
- **Возможности** — **Текст**, **Изображения** и **Структурированный**. Большинству функций нужен структурированный вывод; обработке диктовки, названиям и хронологии нужен только текст.
- **Лимит контекста** — сколько текста модель может прочитать за раз. Если длинные итоги не готовятся из-за ошибки контекста, укажите здесь реальный лимит, настроенный на вашем сервере.

## Модель по умолчанию и модели по функциям

Когда провайдер подключён, выберите, что будет работать в ваших ИИ-функциях, в разделе **Настройки → ИИ-провайдеры → ИИ-функции**:

- **Модель по умолчанию → Стандартный** — используется всеми функциями, когда приватный режим ИИ выключен.
- **Модель по умолчанию → Приватный ИИ** — локальная модель, которая используется, когда приватный режим ИИ включён.
- **Модели по функциям → Настроить** — назначить группе функций свою модель.

Со встроенным ИИ TalkBar по умолчанию использует **Qwen3.5 4B** для итогов и общих функций и **Qwen3 0.6B** для обработки диктовки. Обе модели можно сменить.
