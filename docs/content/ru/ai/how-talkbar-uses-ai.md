TalkBar использует ИИ, чтобы подводить итоги, отвечать на вопросы, обрабатывать диктовку и находить знания в ваших разговорах. Где работает этот ИИ, решаете вы: на этом компьютере, на вашем сервере Ollama или у облачного провайдера с вашим собственным API-ключом. Каждая функция даже может использовать свою модель.

## Два вида ИИ

TalkBar использует модели двух видов.

**Голосовые и вспомогательные модели всегда работают на этом компьютере.** Их работа никогда не передаётся провайдеру, и они не требуют настройки — только однократной загрузки:

- распознавание речи для транскрипта во время записи, команды **Улучшить транскрипт** и диктовки;
- определение голосов и определение речи в звуке;
- [перевод в реальном времени](/voice/live-translation);
- поиск по импортированным документам.

Ваше аудио никогда не отправляется ИИ-провайдерам.

**ИИ-модели (языковые модели)** пишут тексты и рассуждают. Именно их вы распределяете по функциям, и они могут работать как локально, так и в облаке.

## Функции, которые используют ИИ-модель

В настройках ИИ функции объединены в четыре **группы функций**. Каждой группе можно назначить свою модель.

| Группа функций | Функция | Что делает ИИ |
| --- | --- | --- |
| **Чат и запросы к ИИ** | Ответы в чате | Отвечает в чатах [Спросить TalkBar](/chats-and-notes/ask-talkbar), опираясь на ваши сессии, заметки и базу знаний |
| | Спросить ИИ | Пишет или переписывает текст заметки по вашему запросу в строке ИИ |
| **Итоги** | Итоги сессий | Подводит промежуточные и финальные итоги каждой сессии |
| | Хронология | Пишет короткие пункты хронологии во время сессии |
| **Диктовка и голосовые команды** | Обработка диктовки | Приводит продиктованный текст в порядок перед вставкой ([Диктовка](/voice/dictation#обработка-с-ии)) |
| | Интерпретация команд | Понимает команды на естественном языке в чате и сопоставляет их с действиями |
| **База знаний и названия** | Извлечение знаний | Находит воспоминания, людей и компании в сессиях и документах при [поиске знаний](/knowledge/review-and-scans) |
| | Создание названий | Придумывает короткие названия заметок и сессий, если включены автоматические названия |

Модель должна поддерживать то, что нужно функции. Всем функциям нужна текстовая модель. Обработке диктовки, созданию названий и хронологии больше ничего не требуется, поэтому для них хорошо подходят небольшие быстрые модели. Остальным функциям также нужен **структурированный вывод**. TalkBar позволяет выбрать только те модели, которые подходят для функции.

## Как выбирается модель

Какую модель использует каждая функция, определяется в разделе **Настройки → ИИ-провайдеры → ИИ-функции**.

::screenshot{src="/screenshots/ai/ai-features-tab.png" alt="Настройки → ИИ-провайдеры, открыта вкладка «ИИ-функции»: раздел «Модель по умолчанию» со списками «Стандартный» и «Приватный ИИ», кнопка «Проверить» и раздел «Модели по функциям» с кнопкой «Настроить»" caption="Настройки → ИИ-провайдеры → ИИ-функции"}
::

### Модель по умолчанию

**Модель по умолчанию** работает во всех функциях, для которых вы не выбрали отдельную модель. Таких моделей две:

- **Стандартный** — ваш повседневный выбор, используется, когда приватный режим ИИ выключен.
- **Приватный ИИ** — обязательно локальная модель. Используется, когда включён [приватный режим ИИ](/ai/private-ai-mode).

Кнопка **Проверить** отправляет короткий запрос, чтобы убедиться, что модель по умолчанию отвечает.

### Модели по функциям

Нажмите **Настроить** в разделе **Модели по функциям**, чтобы назначить свою модель группе функций (или отдельной функции внутри неё). Например, небольшую быструю модель для обработки диктовки и более крупную — для итогов. Для стандартного и приватного режимов выбор сохраняется отдельно. У функции, которую вы не настраивали, указано **По умолчанию**, и она использует модель по умолчанию; кнопка **Сбросить** возвращает настроенную функцию к модели по умолчанию.

### Выбор для отдельного чата или сессии

- **Чаты**: в каждом чате может быть своя модель. Используйте команду **Сменить модель чата** в чате.
- **Сессии**: в окне **Новая сессия** в строке **ИИ** можно выбрать модель для хронологии и итогов этой сессии или выбрать **Приватный ИИ**, чтобы сессия работала только на локальных моделях. Модель для итогов сессии можно сменить и позже.

## Где работает ИИ и что покидает ваш компьютер

Куда попадает ваш текст, зависит от провайдера, который стоит за моделью.

| Способ | Где работает | Что покидает ваш компьютер |
| --- | --- | --- |
| **Встроенный ИИ** | На этом компьютере, с моделями, скачанными в разделе **Локальный ИИ** | Ничего. После загрузки работает без интернета. |
| **Ollama на этом компьютере** | В приложении Ollama на этом компьютере | Ничего |
| **Ollama на другом компьютере** | На сервере Ollama в вашей сети | Текст, с которым работает функция, передаётся на тот компьютер |
| **Облачный провайдер с вашим API-ключом** | На серверах провайдера (например, Anthropic, OpenAI или Google Gemini) | Текст, с которым работает функция, передаётся этому провайдеру |
| **CLI-инструмент** (например, Claude Code или Codex) | В собственном сервисе инструмента | Текст, с которым работает функция, передаётся через инструмент в его сервис |

«Текст, с которым работает функция» — это то, что нужно конкретной функции: например, текст транскрипта для итогов, ваш вопрос и источники, которые использует чат, для ответа в чате или продиктованные слова для обработки. Аудио в него никогда не входит.

::callout{icon="i-heroicons-lock-closed" color="green"}
Чтобы ничего не попадало к облачным провайдерам или CLI-инструментам, включите [приватный режим ИИ](/ai/private-ai-mode). Он сразу блокирует всех нелокальных провайдеров.
::

### Настройки исходящих запросов

В разделе **Настройки → ИИ-провайдеры → Дополнительно**:

- **Скрыть URL** — убирает полные веб-адреса из содержимого перед отправкой ИИ-провайдеру и заменяет их заглушками.
- **Записывать запросы** — сохраняет локальную копию каждого запроса к ИИ и ответа для диагностики. Журналы остаются на вашем компьютере.
- **Свои инструкции для ИИ** — добавляет к каждому запросу к ИИ вашу короткую заметку (до 300 символов), например вашу роль или желаемый тон.
- **Язык ответов** — задаёт язык, на котором отвечает ИИ. Вариант **Авто (язык интерфейса)** следует языку приложения; в режиме «Авто» ответы в чате следуют языку вашего вопроса.

Кроме того, слова одного человека можно не передавать ИИ с помощью команды [Игнорировать участника](/voice/speakers#как-исключить-участника-из-обработки-ии).

## Настройка ИИ

Быстрее всего начать с окна **Настроить ИИ** (меню логотипа → **Настроить ИИ…** или **Настройки → ИИ-провайдеры → Настроить ИИ**). Оно пошагово проведёт вас через выбор провайдеров и моделей по умолчанию, и его можно открыть снова в любой момент. Подробности — в разделах [Провайдеры и модели](/ai/providers-and-models) и [Локальные модели](/ai/local-models).

## Если ИИ не работает

1. Откройте **Настройки → Диагностика** и нажмите **Проверить всё**. Каждая найденная проблема ведёт к настройке, которая её исправляет.
2. В разделе **Настройки → ИИ-провайдеры** нажмите **Проверить** у провайдера и посмотрите последние ошибки в разделе **Дополнительно → Диагностика**.
3. Если облачный провайдер не отвечает, может появиться уведомление с кнопками **Исправить** или **Включить приватный ИИ**, чтобы перейти на локальные модели.
4. Для локальных моделей проверьте, что они скачаны в разделе **Настройки → Локальный ИИ**.

См. также [Устранение неполадок](/help/troubleshooting).
