**ИИ-инструмент командной строки** (CLI-инструмент) — это небольшая программа от ИИ-компании, например Anthropic, OpenAI, Google или xAI, с которой работают, вводя команды в терминале (CLI — интерфейс командной строки). TalkBar может использовать такой инструмент как ИИ-провайдера: он передаёт инструменту запрос, например подготовить итоги или ответить в чате, а инструмент отвечает через ваш аккаунт в этой компании.

Зачем подключать его к TalkBar:

- **Он может использовать тариф, который у вас уже есть.** Claude Code, Codex, Agy и Grok CLI входят через ваш аккаунт Claude, ChatGPT, Google, SuperGrok или X Premium+, поэтому отдельный API-ключ не нужен. С OpenCode иначе: в зависимости от подключённого в нём ИИ-провайдера может понадобиться API-ключ с отдельной оплатой.
- **Он не зависит от вашей видеокарты.** Когда инструмент использует облачную модель, ИИ работает на серверах компании, поэтому на компьютере без мощной видеокарты он может отвечать быстрее локального ИИ. См. [Как ускорить локальный ИИ](/ai/speed-up-ai).

::callout{icon="i-heroicons-exclamation-triangle" color="amber"}
Когда CLI-инструмент использует облачную модель, текст, с которым работает функция, например транскрипт или заметка, отправляется ИИ-провайдеру, подключённому в этом инструменте. Когда включён [приватный режим ИИ](/ai/private-ai-mode), CLI-инструменты не используются. Если сессии должны оставаться на этом компьютере, используйте встроенный ИИ или Ollama.
::

Разбираться в технике не обязательно. Для каждого инструмента ниже есть короткие шаги установки и готовый промпт: вставьте его в ChatGPT, Claude, Gemini или другой ИИ-ассистент, и он проведёт вас по всем шагам.

## Какой инструмент выбрать

| Инструмент | Что нужно | Вход через |
| --- | --- | --- |
| [Claude Code](#claude-code) | Тариф Claude Pro, Max, Ultra, Team или Enterprise либо аккаунт Claude Console. В бесплатный тариф Claude он не входит. | Аккаунт Claude |
| [Codex](#codex) | Тариф ChatGPT с доступом к Codex, например Plus, Pro, Business, Edu или Enterprise | Аккаунт ChatGPT |
| [Agy](#agy) (Google Antigravity CLI) | Личный аккаунт Google. Подходят бесплатный тариф, Pro и Ultra. | Аккаунт Google |
| [Grok CLI](#grok) (xAI Grok Build) | Тариф SuperGrok или X Premium+ | Аккаунт с этим тарифом |
| [OpenCode](#opencode) (экспериментально) | Node.js и ИИ-провайдер, подключённый в OpenCode. В зависимости от провайдера может понадобиться API-ключ с отдельной оплатой. | Этот провайдер |

Выберите инструмент сервиса, за который вы уже платите. Если такого нет, Agy работает с бесплатным аккаунтом Google.

## Как открыть терминал

Команды установки вводятся в терминале. Скопируйте команду с этой страницы, вставьте её в терминал и нажмите Enter.

::platform-tabs
#windows
1. Нажмите **Пуск**, введите `PowerShell` и выберите **Windows PowerShell**. Запускать его от имени администратора не нужно.
2. Чтобы вставить команду, щёлкните в окне правой кнопкой мыши или нажмите `Ctrl+V`, затем нажмите `Enter`.
#macos
1. Нажмите `Cmd+Пробел`, введите `Терминал` и нажмите `Return`.
2. Чтобы вставить команду, нажмите `Cmd+V`, затем `Return`.
::

После установки инструмента закройте окно терминала и откройте новое, прежде чем проверять. Терминал, открытый заранее, новую программу не видит.

## Claude Code

Claude Code — ИИ-инструмент командной строки от Anthropic. В TalkBar он называется **Claude Code CLI**.

### Что нужно для Claude Code

Тариф Claude Pro, Max, Ultra, Team или Enterprise либо аккаунт Claude Console. В бесплатный тариф Claude Code не входит.

### Установка Claude Code

::platform-tabs
#windows
В PowerShell выполните:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Пока установщик скачивает файлы, он ничего не показывает.
#macos
В Терминале выполните:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Если у вас есть Homebrew, можно также выполнить `brew install --cask claude-code`.
::

Откройте новое окно терминала и проверьте, что всё работает:

```bash
claude --version
```

Команда выводит номер версии, например `2.1.211 (Claude Code)`.

### Вход в Claude Code

Выполните `claude` и войдите в аккаунт Claude, следуя шагам в браузере. После входа закройте окно терминала.

### Подключение Claude Code к TalkBar

Выполните шаги из раздела [Как подключить инструмент к TalkBar](#как-подключить-инструмент-к-talkbar) и выберите **Claude Code CLI**.

### Проблемы с Claude Code

- **Команда `claude` не найдена.** Откройте новое окно терминала. Если установщик сообщил, что папки установки нет в PATH, выполните исправление, которое он показал.
- **Дополнительная проверка.** `claude doctor` проверяет установку и перечисляет проблемы с советами, как их исправить.

Официальная инструкция: [установка Claude Code](https://code.claude.com/docs/en/setup).

## Agy

Agy — это Google Antigravity CLI. В TalkBar он называется **Agy CLI**.

### Что нужно для Agy

Личный аккаунт Google. Подходят бесплатный тариф, Pro и Ultra.

### Установка Agy

::platform-tabs
#windows
В PowerShell выполните:

```powershell
irm https://antigravity.google/cli/install.ps1 | iex
```

Agy устанавливается в папку `C:\Users\<имя пользователя>\AppData\Local\agy\bin`.
#macos
В Терминале выполните:

```bash
curl -fsSL https://antigravity.google/cli/install.sh | bash
```

Agy устанавливается в `~/.local/bin/agy`.
::

Откройте новое окно терминала и проверьте, что всё работает:

```bash
agy --version
```

Команда выводит номер версии.

### Вход в Agy

Выполните `agy`. При первом запуске откроется браузер, чтобы вы вошли в аккаунт Google. После входа закройте окно терминала.

### Подключение Agy к TalkBar

Выполните шаги из раздела [Как подключить инструмент к TalkBar](#как-подключить-инструмент-к-talkbar) и выберите **Agy CLI**.

### Проблемы с Agy

- **В Windows TalkBar не принимает указанный путь.** TalkBar нужен сам файл программы `agy.exe`, а не файл `.cmd` или `.bat`. Официальный установщик кладёт `agy.exe` в папку, указанную выше.

Официальная инструкция: [Antigravity CLI](https://antigravity.google/docs/getting-started?tab=cli).

## OpenCode

OpenCode — ИИ-инструмент командной строки с открытым исходным кодом, который работает со многими ИИ-провайдерами. В TalkBar он называется **OpenCode CLI** и отмечен как **Экспериментально**.

### Что нужно для OpenCode

- **Node.js**, через него устанавливается OpenCode.
- ИИ-провайдер, подключённый в OpenCode. В зависимости от провайдера может понадобиться API-ключ с отдельной оплатой: одни провайдеры работают с подпиской, которая у вас уже есть, другим нужен собственный API-ключ. См. [провайдеры OpenCode](https://opencode.ai/v1/docs/providers/).
- **OpenCode 1.** TalkBar работает с OpenCode 1. Команды ниже устанавливают именно его.

### Установка Node.js

1. Скачайте установщик **LTS** для своей системы с [nodejs.org](https://nodejs.org/en/download) и запустите его с настройками по умолчанию.
2. Откройте новое окно терминала и проверьте, что всё работает:

```bash
node --version
```

### Установка OpenCode

::platform-tabs
#windows
В PowerShell выполните:

```powershell
npm.cmd install -g --allow-scripts=opencode-ai opencode-ai@1
```

Затем откройте новое окно PowerShell и проверьте, что всё работает:

```powershell
opencode.cmd --version
```

В Windows вводите `npm.cmd` и `opencode.cmd`, а не `npm` и `opencode`. Без `.cmd` PowerShell с настройками по умолчанию может остановить команду с сообщением о том, что выполнение сценариев отключено в этой системе.
#macos
В Терминале выполните:

```bash
npm install -g --allow-scripts=opencode-ai opencode-ai@1
```

Затем откройте новое окно Терминала и проверьте, что всё работает:

```bash
opencode --version
```

Если npm останавливается с ошибкой `EACCES` (отказано в доступе), не используйте `sudo`. Вместо этого примените исправление из документации npm: оно переносит глобальную папку npm в вашу домашнюю папку.

```bash
npm config set prefix ~/.local
echo 'PATH=~/.local/bin:$PATH' >> ~/.profile
echo 'source ~/.profile' >> ~/.zprofile
source ~/.profile
```

Затем снова выполните команду установки. Программы из `~/.local/bin` TalkBar может не найти сам; см. [TalkBar не находит инструмент](#talkbar-не-находит-инструмент).

Если у вас есть Homebrew, OpenCode 1 также устанавливается командой `brew install anomalyco/tap/opencode`, без npm. Обычная команда `brew install opencode` устанавливает OpenCode 2.
::

Номер версии должен начинаться с `1`.

`--allow-scripts=opencode-ai` позволяет OpenCode завершить установку. Начиная с npm 12, npm не запускает установочные сценарии пакетов без разрешения, а без своего сценария OpenCode устанавливает заглушку, которая только выводит ошибку. С более старыми версиями npm команда тоже работает.

### Вход в OpenCode

Выполните `opencode auth login` (в Windows — `opencode.cmd auth login`), выберите ИИ-провайдера и следуйте шагам. Затем закройте окно терминала.

### Подключение OpenCode к TalkBar

Выполните шаги из раздела [Как подключить инструмент к TalkBar](#как-подключить-инструмент-к-talkbar) и выберите **OpenCode CLI**.

### Проблемы с OpenCode

- **TalkBar сообщает, что OpenCode не поддерживает обязательный режим `--pure`.** У вас версия, которую TalkBar не может использовать, например OpenCode 2. Установите OpenCode 1 командой выше.
- **`opencode` только сообщает, что его сценарий postinstall не был запущен.** npm пропустил установочный сценарий OpenCode. Снова выполните команду установки выше вместе с `--allow-scripts=opencode-ai`.

Официальная инструкция: [документация OpenCode 1](https://opencode.ai/v1/docs/).

## Как подключить инструмент к TalkBar

Когда инструмент установлен и вы в него вошли:

1. Откройте **Настроить ИИ**: нажмите на логотип TalkBar и выберите **Настроить ИИ…** или нажмите **Настроить ИИ** в разделе **Настройки → ИИ-провайдеры**.
2. Нажмите **Провайдеры** и выберите **CLI-инструменты**. TalkBar ищет Claude Code, Codex, Agy, Grok CLI и OpenCode и помечает каждый как **Обнаружен** или **Не обнаружен**.
3. Нажмите на свой инструмент. TalkBar откроет его модели.
4. Отметьте модели, которые хотите использовать, и нажмите **Далее: выбор модели**.
5. На шаге **Модели по умолчанию** выберите модель и нажмите **Далее: применить**. Выберите **Стандартный**, затем нажмите **Применить**.

Если TalkBar не нашёл ни одного инструмента, нажмите **Показать шаги установки**. На этом шаге для каждого инструмента показаны команды для вашей системы с кнопками **Копировать**, а также **Копировать промпт для ИИ**, **Подробная инструкция** (открывает раздел этого инструмента на этой странице) и **Пошаговая инструкция** (открывает эту страницу). Установив инструмент, нажмите **Проверить CLI снова**.

Инструмент можно добавить и в разделе **Настройки → ИИ-провайдеры → Провайдеры**: нажмите **Добавить провайдера**, выберите **CLI-инструмент** и нужный инструмент. См. [Настройки ИИ-провайдеров](/settings/ai-providers#добавление-провайдера).

Какие функции будут использовать инструмент, выбирается так, как описано в разделе [Модель по умолчанию и модели по функциям](/ai/providers-and-models#модель-по-умолчанию-и-модели-по-функциям).

## Частые проблемы

### TalkBar не находит инструмент

1. Откройте новое окно терминала и выполните команду проверки версии, например `claude --version`. Если и терминал не находит программу, прежде чем устанавливать заново, проверьте, что установщик написал о PATH, и посмотрите проблемы в разделе инструмента. Установщик может завершиться успешно и всё же не добавить свою папку в PATH.
2. Полностью выйдите из TalkBar: нажмите на логотип TalkBar, выберите **Выйти из TalkBar**, затем нажмите **Закрыть** в окне подтверждения. Запустите его снова и нажмите **Проверить CLI снова**. TalkBar ищет программы в папках, которые система сообщает ему при запуске, поэтому инструмент, установленный во время работы TalkBar, может появиться только после перезапуска.
3. Всё равно не находит? Укажите TalkBar, где лежит программа. Узнайте её полный путь:

::platform-tabs
#windows
В PowerShell выполните `where.exe claude`, подставив имя своего инструмента (`claude`, `codex`, `agy`, `grok` или `opencode`). Используйте строку, которая заканчивается на `.exe` или `.cmd`. Для Agy нужен `agy.exe`.
#macos
В Терминале выполните `which claude`, подставив имя своего инструмента (`claude`, `codex`, `agy`, `grok` или `opencode`).

На Mac приложение TalkBar, открытое из Dock или Finder, может не видеть папки, которые использует терминал, например `~/.local/bin`. Если инструмент установлен туда, помогает чаще всего именно этот шаг.
::

Затем откройте **Настройки → ИИ-провайдеры → Провайдеры**, нажмите **Добавить провайдера**, выберите **CLI-инструмент**, выберите инструмент и вставьте путь в поле **Путь к исполняемому файлу**.

### Инструмент сообщает, что вход не выполнен

Снова выполните команду входа из раздела инструмента (`claude`, `codex`, `agy`, `grok login` или `opencode auth login`; в Windows — `opencode.cmd auth login`), завершите вход и повторите действие в TalkBar.

### Через какое-то время запросы перестают выполняться

У тарифа в сервисе есть лимиты использования. Когда вы их исчерпаете, инструмент перестанет отвечать, пока лимит не обновится. При подготовке длинных итогов TalkBar может отправлять до 3 запросов одновременно; если инструмент постоянно упирается в лимиты, выключите **Параллельное выполнение в CLI** в окне редактирования провайдера (см. [Настройки ИИ-провайдеров](/settings/ai-providers#добавление-провайдера)).

### TalkBar не использует инструмент

- Включён [приватный режим ИИ](/ai/private-ai-mode). Пока он включён, CLI-инструменты не используются.
- Инструмент не назначен ни одной функции. См. [Модель по умолчанию и модели по функциям](/ai/providers-and-models#модель-по-умолчанию-и-модели-по-функциям).
- Если ваша организация управляет TalkBar с помощью [политики администратора](/settings/admin-policy), CLI-инструменты могут быть отключены.
