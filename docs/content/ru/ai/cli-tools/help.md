Эта страница для версии TalkBar из Mac App Store. В ней объясняется уведомление **CLI-инструменты не работают в версии из Mac App Store**, которое появляется в разделе **Настроить ИИ → CLI-инструменты**, и чем можно пользоваться вместо них.

## Почему CLI-инструменты не работают

macOS не разрешает приложениям из Mac App Store запускать другие программы. Это правило Apple, а не ошибка, и никакая настройка в TalkBar его не меняет.

TalkBar по-прежнему может видеть на этом Mac Claude Code, Codex, Antigravity (agy), Grok CLI и OpenCode и показывает их в разделе **Настроить ИИ**, но не может выбрать или запустить их. В уведомлении сказано: **macOS не разрешает приложениям из Mac App Store запускать другие программы, поэтому TalkBar видит CLI-инструменты на этом Mac, но не может их использовать.**

## Чем пользоваться вместо них

Эти варианты работают в версии из Mac App Store:

- **Облачные ИИ-провайдеры** со своим API-ключом. Прежде чем провайдер впервые получит содержимое встреч, TalkBar один раз запрашивает ваше согласие для этого провайдера. См. [Провайдеры и модели](/ai/providers-and-models).
- **Локальный ИИ** на этом Mac, на собственных локальных моделях TalkBar. См. [Локальные модели](/ai/local-models).
- **Ollama.** TalkBar подключается к нему по его локальному HTTP API. Ollama нужно установить и запустить отдельно.

## Есть подписка на ИИ?

Используйте MCP в обратную сторону. Ваше ИИ-приложение (Claude Desktop, Claude Code, Codex, ChatGPT, Grok CLI, agy, OpenCode или любой MCP-клиент) подключается к TalkBar. Тогда оно сможет читать ваши встречи и добавлять заметки, задачи и карточки знаний.

В разделе **Настроить ИИ** карточка **Есть подписка на ИИ?** объясняет это так: **Вместо этого подключите своё ИИ-приложение к TalkBar по MCP: оно сможет читать ваши встречи и добавлять заметки, задачи и карточки знаний.**

1. В TalkBar откройте **Настройки → Доступ по MCP**. Карточка **Открыть «Доступ по MCP»** в том же шаге **Настроить ИИ** сразу открывает этот раздел.
2. Включите MCP, выберите вкладку своего ИИ-приложения и скопируйте показанную настройку. В ней уже указан нужный путь. В версии из Mac App Store CLI встроен в приложение: `/Applications/TalkBar.app/Contents/MacOS/talkbar-cli`.
3. Необязательно: **Добавить в PATH** копирует эту команду, чтобы выполнить её в Терминале:

```bash
sudo ln -sf '/Applications/TalkBar.app/Contents/MacOS/talkbar-cli' /usr/local/bin/talkbar-cli
```

Само приложение выполнить её не может, потому что приложения в песочнице не могут запрашивать пароль администратора.

Подробности — в разделе [Обзор MCP и CLI](/mcp/overview). Настройку создаёт приложение; на этой странице конфигурация не повторяется.

## Экспорт

В версии из Mac App Store экспорт, запущенный из CLI или MCP, ставится в очередь, а приложение TalkBar доставляет его в папку или в Notion. Для этого приложение должно быть запущено. Notion подключается в приложении, а не из CLI.
