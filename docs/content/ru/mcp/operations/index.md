TalkBar предоставляет 144 операции (57 на чтение и 87 на изменение): ИИ-ассистентам — через MCP, скриптам — через CLI TalkBar. В этом справочнике описана каждая из них: что она делает, какой инструмент MCP её выполняет, включена ли она по умолчанию, какие у неё аргументы и что она возвращает.

## Как читать этот справочник

У каждой операции свой раздел, заголовок которого — её название (например, `sessions.get`), а под ним строка вида:

**Чтение** · выполняется через [`talkbar_read`](/mcp/tools#talkbar_read) · переключатель MCP по умолчанию **Вкл.** · группа политики `metadata`

| Метка | Значение |
| --- | --- |
| **Тип** | Операции **чтения** только читают данные. Операции **изменения** что-то меняют. |
| **Выполняется через** | Инструмент MCP, который выполняет операцию. Чтение выполняется через [`talkbar_read`](/mcp/tools#talkbar_read). Изменения выполняются через [`talkbar_change`](/mcp/tools#talkbar_change), кроме 15 операций, которые перемещают элементы в корзину, архивируют или удаляют их либо отменяют запланированную встречу: они выполняются только через [`talkbar_delete`](/mcp/tools#talkbar_delete). Такие операции [требуют вашего подтверждения](/mcp/access-and-permissions#подтверждение-удаления), если ваше ИИ-приложение умеет его запрашивать; запросы приложений, которые не умеют, отклоняются, если не включён параметр **Разрешить удаление без подтверждения**. |
| **Переключатель MCP** | Включена ли операция сразу после настройки MCP. Каждую операцию можно включить или выключить в разделе **Настройки → Доступ по MCP**. 81 операция изначально включена, 63 — выключены: операции чтения включены; изменения ваших элементов выключены, а большинство операций с календарём, сериями, планировщиком и экспортом включены. Выключенная операция отвечает `turned_off`. CLI эти переключатели не учитывает. |
| **Группа политики** | Группа, которую политика администратора может разрешить или заблокировать. Если вашим TalkBar управляет организация, заблокированная группа недоступна и через MCP, и через CLI. Подробнее — в разделе [Доступ и разрешения](/mcp/access-and-permissions). |

### Группы политик

| Группа | Что охватывает | Операции |
| --- | --- | --- |
| `metadata` | Названия, количества, списки и расписания без текста встреч: рабочие пространства, тариф, списки сессий и их показатели, записываемая сессия, списки проектов, чтение календаря и серий. | 14 |
| `content` | Чтение, которое возвращает текст встреч: итоги, транскрипты, заметки, чаты, карточки, люди, фрагменты результатов поиска, подготовка к встрече и предпросмотр экспорта. | 35 |
| `contentChanges` | Все изменения сессий, проектов, заметок, задач, базы знаний, людей, тем, закладок, чатов, документов, вашего профиля и названий рабочих пространств. | 62 |
| `scheduling` | Изменения запланированных встреч и серий сессий. | 14 |
| `scheduler` | Просмотр фоновых заданий и управление ими. | 5 |
| `exports` | Настройки, пакеты и доставки экспорта (кроме `exports.preview`, которая входит в `content`). | 14 |

### Аргументы

Для каждого аргумента указан тип, обязательные аргументы отмечены. Диапазоны, допустимые значения и значения по умолчанию берутся из схемы операции; полную схему любой операции также можно получить у [`talkbar_tools`](/mcp/tools#talkbar_tools) с помощью `{"tool": "<operation>"}`.

- **`workspaceId` везде необязателен**, поэтому в списках аргументов не указан. Без него используется рабочее пространство, открытое в приложении. `workspace.list` вообще не принимает аргументов и показывает пространства, которые можно указать.
- Аргумент, который операция не принимает, отклоняется с указанием его имени и никогда не игнорируется. Значение вне допустимого диапазона отклоняется, а не обрезается до границы.
- Поля времени, названия которых оканчиваются на `Ms`, содержат время Unix в миллисекундах (или, где это указано, миллисекунды от начала сессии). В тексте транскрипта и хронологии время показано как `mm:ss` или `h:mm:ss`.
- Если аргумент принимает `null`, то `null` очищает значение, а если аргумент не передан, значение сохраняется.

Коды ошибок, постраничный вывод и лимиты тарифа описаны в разделе [Ошибки и ограничения](/mcp/errors-and-limits).

## Как вызвать операцию

Через MCP передайте операцию и её аргументы инструменту, который её выполняет:

```json
{"tool": "sessions.get", "args": {"sessionId": "ses_123"}}
```

Из командной строки тот же вызов выглядит так:

```bash
talkbar-cli tools call sessions.get --args '{"sessionId":"ses_123"}'
```

Чтобы выполнить по порядку до 20 операций, используйте `{"calls": [...]}`. После ошибки вызовы продолжаются, если не добавить `"stopOnError": true` (по умолчанию `false`). Идентификаторы в примерах на этих страницах условные. Настоящие можно найти через [`talkbar_find`](/mcp/tools#talkbar_find) или операцию получения списка. Подробнее — в разделах [Пять инструментов MCP](/mcp/tools) и [CLI](/mcp/cli).

## Чего ассистенты не могут делать

Ни одна операция не ведёт запись и не управляет ею, не редактирует транскрипт, не подводит итоги, не меняет настройки приложения (исключение — места и правила экспорта через операции `exports.*`), не очищает корзину, не удаляет безвозвратно элементы, у которых есть корзина, и не добавляет документы. Всё это делается только в приложении.
