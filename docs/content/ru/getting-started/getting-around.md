Приведённые ниже сочетания клавиш — значения по умолчанию для Windows. В macOS проверьте сочетание в TalkBar или его настройках; настраиваемые сочетания можно изменить там же.

На этой странице показано, где что находится в главном окне TalkBar и как быстро перемещаться по приложению. Для пошагового знакомства пройдите тур *Знакомство с приложением*: **Помощь → Пройти тур**.

## Боковая панель

В боковой панели слева собраны основные разделы приложения.

| Пункт | Что открывает |
| --- | --- |
| **Главная** | Вашу стартовую страницу. |
| **Идёт запись** | Сессию, которая записывается сейчас. Когда сессия заканчивается, пункт называется **Последняя сессия** и открывает самую недавнюю сессию. Индикатор состояния показывает, что идёт запись, она на паузе или ожидает звука. |
| **Сессии** | Все записанные сессии. Вторая группа **Сессии**, ниже **Проектов**, показывает недавние сессии, которые не входят в проекты. |
| **Чаты** | Ваши разговоры с ассистентом TalkBar. |
| **Заметки** | Ваши собственные заметки. |
| **База знаний** | Карточки знаний, документы, люди, компании и задачи, которые TalkBar хранит для вас. Когда есть ИИ-предложения, ожидающие проверки, под ним появляется пункт **Проверка**. |
| **Проекты** | Ваши проекты — в один клик. В списке не больше пяти проектов, сначала закреплённые; **Все проекты** открывает остальные. Стрелка в строке проекта показывает его последние сессии. Нажмите **+**, чтобы создать проект. |
| **Настройки** | Все настройки. Красный значок означает, что что-то требует вашего внимания. |
| Карточка аккаунта | В самом низу: ваш профиль и активное рабочее пространство. Нажмите, чтобы сменить пространство или управлять аккаунтом. |

Наведите указатель на сессию в боковой панели, чтобы увидеть небольшую карточку с её шаблоном, датой, длительностью, участниками, проектом и источником.

Кнопкой в верхней части боковой панели её можно свернуть в узкую полосу. Чтобы закрепить под разделом «База знаний» значки-ссылки на его страницы, например **Документы** или **Люди**, включите **Ярлыки базы знаний** в **Настройки → Общие → Внешний вид**.

## Заголовок окна

| Элемент | Что делает |
| --- | --- |
| **Логотип TalkBar** | Открывает меню TalkBar: **О TalkBar** (с вашей версией и тарифом), **Перейти на {plan}** (когда доступен тариф выше), **Проверить обновления**, подменю **Настройки** со всеми вкладками, **Настроить ИИ…**, **Включить приватный режим ИИ** или **Выключить приватный режим ИИ** (когда режим доступен), **Показать панель сессии** (или **Скрыть панель сессии**), **Закрыть окно** и **Выйти из TalkBar**. |
| **Новая сессия** | Открывает окно новой сессии, чтобы начать запись. |
| **Начать запись** | Появляется рядом с кнопкой **Новая сессия**, когда запланированная сессия уже началась, а запись не идёт. Нажмите, чтобы начать эту сессию. |
| **Предстоящие** | Список запланированных сессий. У сессии, которая скоро начнётся, появляется кнопка **Начать**. **Показать все** открывает страницу предстоящих сессий, а **Запланировать** — окно планирования. |
| **Режим фокуса** | Показывается на экране записи. См. [Макеты](/sessions/recording#макеты). |
| **Помощь** | **Пройти тур**, **Документация** и **Связаться с нами**. На бесплатном тарифе, если на компьютере ещё не было пробного периода тестовой версии, есть и **Активировать приглашение**. См. [Пробный период тестовой версии](/settings/license#пробный-период-тестовой-версии). |

Когда включён приватный режим ИИ, логотип превращается в зелёный щит — напоминание о том, что все ИИ-функции работают только на локальных моделях. См. [Приватный режим ИИ](/ai/private-ai-mode).

**Закрыть окно**, как и кнопка закрытия окна, сворачивает TalkBar в область уведомлений, где приложение продолжает работать. **Выйти из TalkBar** спрашивает, полностью выйти (**Закрыть**) или оставить приложение работать в трее (**Свернуть в трей**).

## Системный трей

Пока TalkBar работает, его значок находится в системном трее, даже если главное окно закрыто. Значок меняется, когда идёт запись или она на паузе.

::platform-tabs
#windows
Нажмите на значок, чтобы открыть главное окно. Нажмите правой кнопкой, чтобы открыть меню.
#macos
Нажмите на значок в строке меню, чтобы открыть меню.
::

| Пункт меню | Что делает |
| --- | --- |
| **Начать сессию** | Сразу начинает запись. |
| **Новая сессия…** | Открывает окно новой сессии. |
| Состояние сессии, **Приостановить сессию** или **Продолжить сессию**, **Завершить сессию** | Во время записи показываются вместо двух пунктов выше. Нажмите на состояние, чтобы открыть текущую сессию. |
| **Запланировать сессию…** | Открывает окно планирования. |
| **Предстоящие сессии** | Ближайшие запланированные сессии и **Все предстоящие сессии**. |
| **Недавние сессии** | Последние 10 сессий и **Все сессии**. |
| **Быстрые действия** | Те же пункты, что и на кнопке [быстрых действий](#быстрые-действия). |
| **Настройки** | **Все настройки…** и ссылки на вкладки настроек. |
| **Приватный режим ИИ** | Включает или выключает [приватный режим ИИ](/ai/private-ai-mode), когда режим доступен. Пока идёт сессия, пункт заблокирован. |
| **Открыть TalkBar** | Открывает главное окно. |
| **Выход** | Закрывает TalkBar. |

## Главная

Главная — стартовая страница активного рабочего пространства.

- В приветствии указано название активного **пространства**. Кнопка **Новая сессия** начинает запись.
- Меню **Добавить** создаёт новый элемент: **Чат**, **Заметка**, **Контакт**, **Компания** или **Карточка знаний**.
- Четыре плитки показывают, сколько у вас элементов в разделах **Сессии**, **Чаты**, **Заметки** и **Документы**. Нажмите на плитку, чтобы открыть соответствующий список.
- Блок **Скоро** появляется, когда на ближайшее время запланированы сессии. Начните сессию или откройте её подготовку.
- Меню периода задаёт, насколько далеко в прошлое уходит список недавнего, например **Сегодня** или **Эта неделя**. Нажмите **Сделать основным**, чтобы сохранить выбор.
- Список недавнего показывает последние сессии, заметки и чаты по дням. Переключайтесь между **Все** и **Закреплённые**, фильтруйте по типу и ищите. Значок в строке закрепляет элемент или снимает закрепление, а **Закреплённые сверху** показывает закреплённые элементы первыми.

## Общий поиск

Нажмите `Ctrl+K` (`Cmd+K` в macOS) или щёлкните по полю поиска в верхней части боковой панели, чтобы искать по всему рабочему пространству. Вне текстовых полей поиск открывает и клавиша `/`.

Поиск находит сессии, заметки, чаты, задачи, документы, карточки знаний, людей, компании, проекты и серии. Совпадения в тексте транскрипта, итогов или документа помечаются соответствующим образом.

В редакторе заметок эти клавиши работают по-другому: `/` открывает меню команд редактора, а `Ctrl+K` вставляет ссылку.

Чтобы найти настройку, воспользуйтесь полем **Найти настройку…** в верхней части боковой панели настроек.

## Быстрые действия

Круглая кнопка в правом нижнем углу открывает **Быстрые действия** — ярлыки для частых задач. По умолчанию там есть **Главная**, **Новая сессия**, **Сессии**, **Чат** и **Настройки**. Можно также добавить «Идёт запись», «Календарь», «Чаты», «База знаний», «Заметки», «Документы» и «Проекты».

Выбрать пункты и изменить их порядок можно в **Настройки → Быстрые действия**. См. [Настройки быстрых действий](/settings/quick-actions).

## Панель сессии

Панель сессии — небольшое плавающее окно, которое остаётся поверх других приложений.

- Во время записи она показывает сессию в компактном виде с последними словами текущего участника.
- Когда включено распознавание сессий и микрофон свободен, TalkBar прислушивается на этом компьютере, не начался ли разговор, и предлагает начать сессию прямо с панели. Звук и текст никогда не покидают это устройство, и ничего не сохраняется, пока вы не начнёте сессию.

Показать или скрыть панель можно из меню логотипа TalkBar или сочетанием `Ctrl+Alt+B`. Панель можно перетащить в любое место. Распознавание, сочетание клавиш, положение панели, число показываемых строк и **Пауза при пропуске** (на сколько кнопка пропуска на панели приостанавливает распознавание) настраиваются в **Настройки → Общие → Распознавание сессий**. По умолчанию распознавание сессий включено.

## Напоминания

Панель напоминания не нужно открывать: она появляется сама. Когда у запланированной сессии наступает время напоминания, панель всплывает в правом нижнем углу TalkBar поверх кнопки быстрых действий, и одновременно появляется системное уведомление.

На панели показаны название и время сессии. **Начать** начинает сессию, **Отложить: 10 мин** напомнит позже (стрелка рядом предлагает другое время), **Пропустить** пропускает эту сессию, а **X** закрывает панель. Для сессии, которая начинается сама, панель показывает обратный отсчёт. См. [Напоминания и автозапуск](/sessions/scheduling-and-preparing#напоминания-и-автозапуск).

## Обучающие туры

Туры указывают на реальные элементы экрана и шаг за шагом объясняют их.

- **Помощь → Пройти тур** открывает выбор тура, в котором уже выбран тур для текущего экрана.
- В **Настройки → Помощь и туры** перечислены все туры по группам и показано, сколько вы прошли. Здесь можно **Начать** тур или **Повторить** его.
- Чтобы остановить тур, нажмите `Esc` или **Пропустить тур**. Пропущенный тур помечается, чтобы к нему можно было вернуться.
- Когда тур пройден, TalkBar обычно предлагает следующий из той же группы.

Пока идёт тур, на щелчки реагирует только выделенная часть экрана.

## Сочетания клавиш

### В приложении

| Сочетание | Что делает |
| --- | --- |
| `Ctrl+K` | Открыть или закрыть поиск. |
| `/` | Открыть поиск (вне текстовых полей и редакторов). |
| `Esc` | В поиске — очистить запрос, затем закрыть поиск. Во время тура — остановить тур. На экране записи — выйти из режима фокуса. |
| `Ctrl+J` | В заметке — перейти к строке ИИ **Что написать или изменить…**. |
| `Ctrl+Shift+O` | В чате — начать новый чат с теми же параметрами. |
| `Shift+Esc` | На странице «Чаты» — вернуться к полю сообщения. |
| `J` / `K` | На странице **Проверка** базы знаний — перейти к следующему или предыдущему предложению. |
| `A` / `E` / `D` / `S` | На странице **Проверка** — одобрить, изменить, отклонить или отложить текущее предложение. |
| `Space` | На странице **Проверка** — выбрать текущее предложение. |

### Везде на компьютере

Эти сочетания работают, даже когда TalkBar в фоне. Каждое из них можно изменить или отключить в настройках.

| Сочетание | Что делает | По умолчанию | Где изменить |
| --- | --- | --- | --- |
| Удерживать `Ctrl+Shift` | Начать или остановить диктовку. Короткое нажатие ничего не делает. | Вкл. | **Настройки → Голос → Диктовка → Сочетание для диктовки** |
| `Ctrl+Shift+Enter` | Во время диктовки вставить уже надиктованное и продолжить запись. | Вкл. | **Настройки → Голос → Диктовка → Вставка во время записи** |
| `Ctrl+Shift+L` | Обработать диктовку с помощью ИИ и вставить её. Работает, только когда включена **Обработка с ИИ**. | Вкл. | **Настройки → Голос → Диктовка → Сочетание для обработки** |
| `Ctrl+Shift+M` | Выключить или включить весь звук с микрофона для приложения TalkBar. На другие приложения не влияет. | Вкл. | **Настройки → Голос → Запись → Отключение микрофона** |
| `Ctrl+Alt+B` | Показать или скрыть панель сессии. | Вкл. | **Настройки → Общие → Распознавание сессий → Сочетание панели** |
| `Ctrl+Shift+Space` | Открыть главное окно TalkBar и перевести на него фокус. | Выкл. | **Настройки → Общие → Запуск → Сочетание показа TalkBar** |

Если сочетание уже занято другим приложением, TalkBar сообщит об этом и попросит выбрать другое. Сочетания клавиш проверяет и **Настройки → Диагностика**. См. [Диктовка](/voice/dictation).

## Язык интерфейса

Интерфейс TalkBar доступен на 15 языках: English, Español, Deutsch, Français, Italiano, Русский, Türkçe, Polski, Українська, 简体中文, Português (Brasil), Português (Portugal), 日本語, 한국어 и 繁體中文.

Язык выбирается при первой настройке, а позже — в **Настройки → Общие → Язык интерфейса приложения**. Изменение применяется сразу, в том числе в панели сессии и панели диктовки. Как изменить отдельные формулировки, см. в разделе [Свои переводы](/settings/general#свои-переводы).

::callout{icon="i-heroicons-information-circle" color="gray"}
Некоторые региональные лицензии включают только определённые языки интерфейса. Если язык недоступен, TalkBar объяснит причину и даст ссылку на **Настройки → Лицензия**.
::

Язык интерфейса не связан с языком, на котором TalkBar распознаёт речь. Его задают в **Настройки → Голос → Распознавание речи**. См. [Запись и распознавание речи](/voice/recording-and-transcription).
