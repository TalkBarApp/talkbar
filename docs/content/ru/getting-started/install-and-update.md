Скачайте TalkBar для вашего компьютера с GitHub, установите приложение и поддерживайте его в актуальном состоянии.

## Скачивание и установка

::platform-tabs
#windows
1. Откройте [последний выпуск](https://github.com/TalkBarApp/talkbar/releases/latest) на GitHub.
2. В разделе **Assets** скачайте `TalkBar_<version>_x64-setup.exe`.
3. Запустите установщик и следуйте его шагам.

Установщик подписан. Если Microsoft Edge WebView2 отсутствует, установщик загрузит его через интернет.
#macos
Версия для Mac в разработке. Когда она будет готова, файл для скачивания и инструкции появятся на странице [последнего выпуска](https://github.com/TalkBarApp/talkbar/releases/latest).
::

## Первый запуск

При первом запуске TalkBar окно приветствия проведёт вас через настройку: ваше имя, язык приложения, где работает ИИ, а также модели распознавания речи и голосов, которые нужны каждой сессии. Пропустить настройку нельзя, но можно выйти и продолжить с того же места при следующем запуске TalkBar. См. [Первая настройка](/getting-started/first-run-setup).

Если закрыть главное окно, TalkBar продолжит работать в области уведомлений. Чтобы полностью выйти, нажмите на логотип TalkBar и выберите **Выйти из TalkBar**.

## Автоматические обновления

TalkBar проверяет обновления в фоне. Когда выходит новая версия, приложение скачивает её и устанавливает при следующем запуске TalkBar.

О ходе обновления сообщает баннер в верхней части окна:

| Баннер | Что он означает |
| --- | --- |
| **Доступна версия TalkBar {version}** | Найдена новая версия. Нажмите **Скачать обновление**, чтобы получить её сейчас, или **Список изменений**, чтобы узнать, что нового. |
| **Доступна версия TalkBar {version}** и **Перезапустите TalkBar, чтобы завершить обновление до {version}** | Обновление скачано и готово. Нажмите **Перезапустить** или продолжайте работать — обновление установится при следующем запуске TalkBar. |
| **Доступна версия TalkBar {version}** и примечание, что ваша лицензия включает версии, выпущенные до определённой даты | В этой версии будет действовать бесплатный тариф. Нажмите **Продлить обновления**, чтобы сохранить в ней свой тариф, или **Всё равно установить**, чтобы установить её сейчас. **Список изменений** показывает, что нового. |
| **TalkBar обновлён** | Обновление установлено. Нажмите **Список изменений**, чтобы узнать, что нового. |

Если подготовить обновление не удалось, баннер сообщает причину и предлагает **Повторить подготовку**.

Перезапустить приложение для обновления нельзя, пока идёт запись, диктовка или обработка транскрипта. TalkBar попросит сначала их завершить.

::

### Проверка обновлений вручную

- Нажмите на логотип TalkBar в заголовке окна и выберите **Проверить обновления**.
- Или в настройках нажмите **Проверить обновления** внизу боковой панели настроек.

Если у вас уже последняя версия, появится сообщение **Обновлений нет**.

### Отключение автоматических обновлений

Настройка **Автообновления** находится в **Настройки → Общие → Обновления**.

| Настройка | Что делает | По умолчанию |
| --- | --- | --- |
| **Автообновления** | Автоматически скачивает обновления и устанавливает их при следующем запуске TalkBar. На платном тарифе её можно отключить. На бесплатном тарифе она всегда включена. | Вкл. |
| **Бета-версии** | Получать только бета-версии, чтобы пробовать новые функции. Отключите, чтобы проверять только стабильные версии. | Выкл. |

Если ваша лицензия включает обновления, выпущенные до определённой даты, эта дата видна в разделе «Обновления». Перед установкой более новой версии TalkBar спросит разрешения — даже при включённых автообновлениях, потому что в этой версии будет действовать бесплатный тариф. См. [Тарифы и лицензия](/data/plans-and-license).

::callout{icon="i-heroicons-information-circle" color="gray"}
Если приложением TalkBar управляет ваша организация, настройки обновлений могут быть заблокированы и показывать сообщение **Этой настройкой управляет ваша организация.** Организация также может принудительно включить или выключить автообновления или отключить ручную проверку обновлений. См. [Политика администратора](/settings/admin-policy).
::

## Каналы выпусков

| Выпуск | Номер версии | Для кого |
| --- | --- | --- |
| Последний выпуск | `vX.Y.Z` | Для всех |
| Бета-версия | `vX.Y.Z-beta.N` | Для бета-тестировщиков, которые пробуют новые функции. Чтобы получать такие версии, включите **Бета-версии**. |

### Отказ от бета-версий

Отключите **Бета-версии** в **Настройки → Общие → Обновления**. Текущая бета-версия останется у вас, пока не выйдет более новая стабильная версия, а затем TalkBar обновится до неё.

Если доступна более старая стабильная версия, появится также кнопка **Вернуться на стабильную**. Она устанавливает эту более старую версию. Данные бета-версии могут оказаться с ней несовместимы, поэтому TalkBar покажет предупреждение и перед установкой создаст резервную копию базы данных.

## Подписанные обновления

Каждое обновление подписано, и TalkBar проверяет подпись перед установкой. Если проверка не пройдена, обновление не устанавливается и появляется сообщение **Не удалось проверить обновление. Попробуйте позже.**

## Удаление TalkBar

::platform-tabs
#windows
Удалите TalkBar в разделе **Приложения** параметров Windows.
#macos
Выйдите из TalkBar и удалите приложение обычным для macOS способом.
::

Если ваши сессии могут понадобиться позже, перед удалением создайте резервную копию: **Настройки → Данные и резервные копии → Создать копию** сохраняет данные в ZIP-файл. См. [Резервное копирование и восстановление](/data/backup-and-restore).

Сессии, записи, заметки и скачанные модели хранятся в папке данных TalkBar. Перед удалением найдите её через **Настройки → Данные и резервные копии → Открыть папку данных**. Чтобы полностью удалить данные TalkBar с компьютера, после удаления приложения проверьте, исчезла ли эта папка, и удалите её, если она осталась.

::callout{icon="i-heroicons-exclamation-triangle" color="amber"}
Удаление папки данных безвозвратно стирает ваши сессии, записи, заметки и базу знаний. Если сомневаетесь, сначала создайте резервную копию.
::
