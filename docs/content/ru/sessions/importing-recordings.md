Уже есть запись встречи, лекции или звонка? Импортируйте её, и TalkBar превратит её в сессию — такую же, как записанная вживую: транскрипт по участникам, хронология, итоги и название. Распознавание речи идёт на вашем компьютере.

## Поддерживаемые файлы

| | |
| --- | --- |
| **Форматы** | mp3, wav, m4a, mp4, aac, flac, ogg, opus, mkv, webm |
| **Максимальный размер** | 1 ГБ |
| **Максимальная длительность** | 6 часов |

Видеофайлы (mp4, mkv, webm) тоже подходят: TalkBar берёт из них звуковую дорожку.

## Импорт файла

1. Нажмите **Новая сессия** и настройте сессию как обычно: выберите [шаблон](/sessions/templates-and-skills) и при желании проект, серию, контекст, язык итогов, длину итогов и режим конфиденциальности. См. [Начало сессии](/sessions/starting-a-session).
2. В разделе **Шаблон** нажмите **Загрузить аудиофайл**.
3. Перетащите файл в окно или нажмите, чтобы выбрать его.
4. Выберите параметры, описанные ниже, и нажмите **Начать импорт**.

::screenshot{src="/screenshots/sessions/upload-audio-file.png" alt="Окно «Загрузить аудиофайл» с выбранным файлом mp3, выбором участников, списками «Модель распознавания речи» и «Модель для итогов» и кнопкой «Начать импорт»" caption="Окно «Загрузить аудиофайл»"}
::

| Параметр | Что делает |
| --- | --- |
| **Участники** | **Только вы** — самый быстрый вариант: определение голосов пропускается. **Вы + 1**, **Несколько (2–4)** и **Много (5–8)** разделяют, кто что сказал. |
| **Модель распознавания речи** | Модель, которая распознаёт речь в файле. Если модель ещё не установлена, её можно скачать прямо в этом окне. |
| **Модель для итогов** | ИИ-модель для записей хронологии и итогов. **По умолчанию** — модель из ваших настроек. В сессии с приватным ИИ итоги подводит встроенная локальная модель. |

Остальные настройки сессия берёт из окна «Новая сессия»: шаблон, проект, режим конфиденциальности и другие.

::callout{icon="i-heroicons-light-bulb" color="primary"}
Если модель определения голосов не скачана, окно сообщит об этом и предложит её скачать. См. [Участники](/voice/speakers).
::

## Что происходит при импорте

Окно **Импорт аудиофайла** показывает каждый этап и сколько времени он занял:

1. **Декодирование звука** и **Преобразование звука**: файл читается и сохраняется как аудио сессии.
2. **Поиск речи**: находятся фрагменты, где люди говорят.
3. **Распознавание речи**: распознаётся каждый фрагмент и определяются голоса.
4. **Сохранение транскрипта**.
5. **Хронология**: пишутся заметки хронологии.
6. **Подводим итоги**.
7. **Выбор названия**: TalkBar предлагает название сессии.

Окно можно не закрывать. Когда импорт завершится, нажмите **Посмотреть сессию**, чтобы открыть её. Импортированные сессии считаются завершёнными, а в их заголовке указано **Из аудиофайла**.

Чтобы продолжить работу во время импорта, нажмите **Обработать в фоне**. В списке сессий у такой сессии будет статус **Импорт**, а когда всё будет готово, придёт уведомление **Импорт аудио завершён**. Нажмите **Посмотреть сессию** в уведомлении, чтобы открыть её.

## Отмена импорта

Нажмите **Отменить импорт**. Если часть файла уже распознана, TalkBar сохранит её как сессию. Если ещё ничего не распознано, пустая сессия удаляется.

## Полезно знать

- Одновременно выполняется только один импорт. Пока он идёт, начать запись новой сессии нельзя, но можно запланировать сессию на потом.
- Импортированное аудио хранится вместе с сессией: его можно прослушать, а позже — запустить **Улучшить транскрипт**. См. [Подробности сессии](/sessions/session-details#улучшить-транскрипт).
- На бесплатном тарифе импорт учитывается в лимите сессий рабочего пространства. См. [Ограничения тарифа](/sessions/overview#ограничения-тарифа).
- Если импорт не удался, окно показывает **Ошибка импорта аудио** и причину.
