**Шаблон сессии** — это тип сессии, например командная встреча, 1:1 или лекция. Он определяет, какие разделы будут в итогах, на что ИИ должен обращать внимание, а также настройки звука и участников по умолчанию. **Навыки** — готовые промпты для ИИ, которые вы выбираете в чате, например *Письмо по итогам*. И то и другое настраивается в разделе **Настройки → Шаблоны и навыки**.

## Шаблоны сессий

Шаблон выбирается, когда вы [начинаете сессию](/sessions/starting-a-session). Он влияет на сессию в трёх отношениях:

- **Разделы итогов**: итоги всегда начинаются с обзора и главных выводов, затем идут разделы шаблона, например *Решения* или *Задачи и ответственные*.
- **Указания для ИИ**: описание типа сессии, свои инструкции для ИИ и словарь помогают ИИ вести хронологию и подводить итоги.
- **Параметры записи по умолчанию**: источник звука и ожидаемое число участников.

Когда сессия начинается, она сохраняет собственную копию шаблона. Если потом изменить шаблон, существующие сессии не изменятся, пока вы не подведёте их итоги заново.

### Встроенные шаблоны

В приложении TalkBar есть **28 встроенных шаблонов** в шести категориях. **15 из них включены** по умолчанию и доступны, когда вы начинаете сессию. Остальные можно включить в разделе **Настройки → Шаблоны и навыки → Шаблоны сессий**. Шаблон по умолчанию — **Встреча**.

Включены по умолчанию:

| Категория | Шаблоны |
| --- | --- |
| **Встречи** | Встреча, Очная встреча |
| **Звонки и 1:1** | 1:1, Звонок |
| **Интервью** | Интервью |
| **Прослушивание** | Прослушивание, Подкаст, Лекция, Познавательное выступление, Обзор и оценка, Презентация продукта |
| **Соло** | Голосовая заметка, Мозговой штурм, Репетиция выступления, Тренировка ясной речи |

Выключены по умолчанию:

| Категория | Шаблоны |
| --- | --- |
| **Встречи** | Воркшоп с клиентом, Совет директоров / руководство |
| **Звонки и 1:1** | Коучинг-сессия |
| **Клиенты и сделки** | Первый звонок с лидом, Обзор с клиентом / QBR, Звонок с инвестором или основателем, Юридическая консультация |
| **Интервью** | Собеседование, Пользовательское интервью, Выпуск подкаста (ведущий) |
| **Прослушивание** | Вебинар, Практическое руководство, Панельная дискуссия |

Шаблоны, которые вы создаёте, дублируете или импортируете, попадают в седьмую категорию — **Свои**. Можно также ввести собственное название категории.

::callout{icon="i-heroicons-light-bulb" color="primary"}
Тренировочные шаблоны (*Репетиция выступления* и *Тренировка ясной речи*) добавляют разбор подачи и варианты более точных формулировок, а в их сессиях показываются **Слов в минуту** и **Самая длинная пауза**.
::

### Управление шаблонами

::screenshot{src="/screenshots/sessions/templates-settings.png" alt="Настройки, раздел «Шаблоны и навыки», вкладка «Шаблоны сессий»: кнопки «Новый шаблон» и «Импорт», поле поиска и фильтр по категориям, группа «Закреплено» и карточки шаблонов по категориям, на каждой — число разделов и переключатель" caption="Шаблоны сессий в настройках"}
::

В разделе **Настройки → Шаблоны и навыки → Шаблоны сессий**:

- Переключатель на карточке включает или выключает шаблон. Когда вы начинаете сессию, доступны только включённые шаблоны.
- **Закрепите** шаблон (в его меню), чтобы он предлагался первым, когда вы начинаете или планируете сессию. Закреплённые шаблоны можно перетаскивать, меняя их порядок.
- Нажмите **Новый шаблон**, чтобы создать шаблон, или **Импорт**, чтобы добавить шаблоны из файла.
- Используйте поиск или фильтр по категории.

Меню каждой карточки:

| Действие | Что делает |
| --- | --- |
| **Изменить** | Открывает редактор шаблона. Встроенные шаблоны тоже можно изменять. |
| **Закрепить** / **Открепить** | Шаблон предлагается первым, когда вы начинаете сессию. |
| **Дублировать** | Создаёт копию, которую можно изменять. |
| **Сделать основным** | Новые сессии будут начинаться с этого шаблона. |
| **Экспорт…** | Сохраняет шаблон в файл Markdown, которым можно поделиться или который можно импортировать в другом месте. |
| **Восстановить исходный** | Для изменённого встроенного шаблона: возвращает исходную версию. Существующие сессии сохраняют свою копию. |
| **Удалить** | Только для ваших шаблонов. У завершённых сессий останутся их итоги. |
| **Создать шаблон заметки из заголовков** | Создаёт [шаблон заметки](#шаблоны-заметок) с теми же заголовками. |

Шаблон по умолчанию можно также выбрать в разделе **Настройки → Общие → Параметры сессий → Шаблон по умолчанию**, в том числе вариант **Запоминать последний шаблон**.

### Создание и изменение шаблона

Редактор шаблона состоит из таких частей:

| Часть | Что вы задаёте |
| --- | --- |
| **Общие** | **Название**, **Значок**, **Категория** и однострочное **Описание**. |
| **Контекст сессии** | Что это за сессии, кто в них участвует и что важно (до 2 000 символов). Все итоги пишутся с учётом этого. |
| **Разделы** | Разделы итогов по порядку. См. ниже. |
| **Дополнительно** → **Запись** | Источник звука и ожидаемое число участников. |
| **Дополнительно** → **Заметки по ходу** | Стиль хронологии во время записи: **Личные заметки**, **Контент** (следить за тем, что показывают) или **Разговор** (отслеживать, кто что сказал), а также дополнительные указания. |
| **Дополнительно** → **База знаний** | **Фокус для базы знаний**: на что обращать внимание, сохраняя знания из этих сессий. |
| **Дополнительно** → **Словарь** | Имена, продукты и жаргон, у каждого — необязательная подсказка, чтобы ИИ писал их правильно. |
| **Дополнительно** → **Свои инструкции для ИИ** | Дополнительные указания для итогов: тон, оформление, что всегда включать или чего избегать (до 1 000 символов). |

Когда закончите, нажмите **Сохранить шаблон**.

## Разделы итогов

Каждый раздел — это одна часть итогов. У раздела есть:

| Поле | Что делает |
| --- | --- |
| **Заголовок раздела** | Заголовок в итогах (до 80 символов). |
| **Инструкции раздела** | Что ИИ должен извлечь для этого раздела (до 500 символов). |
| Формат | Как оформляются пункты: **Пункты**, **Пункты с ответственными**, **С отметками времени**, **Абзац** или **Вопросы и ответы**. |

В шаблоне может быть до 10 разделов. В редакторе разделы можно перетаскивать, меняя их порядок, а кнопка **Добавить раздел** добавляет новый. В меню **Параметры раздела** можно **Изменить** раздел, сменить его формат, **Отключить раздел** (он остаётся в шаблоне, но не попадает в итоги), **Восстановить раздел** (для изменённого встроенного раздела) или **Удалить раздел**.

Вкладка **Разделы итогов** в разделе **Настройки → Шаблоны и навыки** показывает контекст сессии и разделы всех шаблонов в одном месте, сгруппированные по шаблонам. Там их тоже можно изменять и переставлять.

### Разделы для одной сессии

Разделы отдельной сессии можно изменить, не трогая её шаблон:

- Перед началом: в окне «Новая сессия» нажмите **Настроить** рядом с **Разделы**.
- После остановки: откройте меню **ИИ** в итогах и выберите **Разделы итогов**.

В обоих местах можно включать и выключать разделы или нажать **Добавить раздел**, чтобы взять раздел из другого включённого шаблона. В сессии может быть включено до 12 разделов. Затем подведите итоги заново, чтобы применить изменения. См. [Подробности сессии](/sessions/session-details#итоги).

## Навыки

**Навык** — это готовый промпт, который помогает ИИ писать или анализировать ваши сессии и заметки. Навык выбирается в чате: нажмите **Навыки** в поле сообщения или введите **/** в пустом поле и выберите нужный. Навык применяется к этому запросу, а результатом будет ответ в чате. Навыки не запускаются сами и не меняют итоги сессии. См. [Как применить навык](/chats-and-notes/ask-talkbar#как-применить-навык).

В приложении TalkBar 24 встроенных навыка, все они включены:

| Группа | Навыки |
| --- | --- |
| **Перед сессией** | Составить повестку, Предложить вопросы, Прошлые обязательства, Справка об участнике |
| **Во время сессии** | Что я пропустил, Объяснить термин, Следующие вопросы, Нерешённые вопросы |
| **После сессии** | Письмо по итогам, Краткий пересказ, Выделить задачи, Зафиксировать решения, Риски и слепые зоны, Цитаты |
| **По нескольким сессиям** | Итоги недели, История решения, Повторяющиеся отзывы, Кто за что отвечает, Запросы руководства |
| **Текст и редактура** | Улучшить заметки, Сократить текст, Дополнить по источникам, Описание проекта, Тикет для разработки |

### Управление навыками и создание своих

В разделе **Настройки → Шаблоны и навыки → Навыки** можно включать и выключать навыки, закреплять самые нужные, искать их и фильтровать по группе. Нажмите на навык и выберите **Открыть в чате**, чтобы начать с ним чат.

Нажмите **Новый навык**, чтобы написать свой, или **Импорт**, чтобы добавить навык из файла Markdown или текстового файла. У навыка есть **Название**, **Значок**, **Группа**, однострочное **Описание** и **Инструкции для ИИ / промпт** (до 4 000 символов). В меню каждого навыка также есть **Изменить**, **Дублировать**, **Экспорт**, **Восстановить исходный** и **Удалить**.

Когда вы используете навык в чате, его инструкции можно изменить для одного запроса, не меняя сохранённый навык.

## Навыки для базы знаний

На вкладке **База знаний** хранятся навыки для базы знаний: они определяют, что ищет сканирование документа, когда готовит черновики [карточек знаний](/knowledge/knowledge-cards), например *Факты и цифры* или *Термины и определения*. Выберите до 3 навыков по умолчанию — они будут заранее отмечены при каждом сканировании. См. [Проверка и поиск знаний](/knowledge/review-and-scans).

## Шаблоны заметок

В приложении TalkBar также есть **44 шаблона заметок** для структурированных заметок в таких категориях, как продажи, разработка, продукт, руководство, найм и личное. Управлять ими можно в разделе **Настройки → Шаблоны и навыки → Шаблоны заметок**, а вставить шаблон в заметку — командой `/template`. См. [Заметки](/chats-and-notes/notes).

## Ограничения тарифа

| Тариф | Встроенные шаблоны | Создание, изменение и импорт шаблонов | Создание своих навыков |
| --- | --- | --- | --- |
| Бесплатный, Personal | Да | Нет | Нет |
| Plus | Да | Да | Нет |
| Pro, Business | Да | Да | Да |

Свои навыки включают и навыки для базы знаний. На любом тарифе можно просматривать шаблоны и навыки, включать и выключать их, закреплять, выбирать шаблон по умолчанию, экспортировать их, восстанавливать встроенные и удалять свои. См. [Тарифы и лицензия](/data/plans-and-license).
