Приведённые ниже сочетания клавиш — значения по умолчанию для Windows. В macOS проверьте сочетание в TalkBar или его настройках; настраиваемые сочетания можно изменить там же.

Любая запись начинается в окне **Новая сессия**. Вы выбираете тип сессии, источник звука и число участников, а затем нажимаете **Начать сессию**. Всё остальное необязательно и уже настроено разумно по умолчанию.

## Как начать сессию

- Нажмите **Новая сессия** в строке заголовка.
- Нажмите **Начать сессию** на странице **Сессии** или на главной.
- Нажмите **Начать** у запланированной сессии в разделе **Предстоящие сессии**. Окно откроется с настройками, подготовленными для этой сессии. (**Начать** в напоминании или у сессии, которая вот-вот начнётся, в полосе **Скоро** сразу запускает запись.) См. [Планирование и подготовка](/sessions/scheduling-and-preparing).
- Воспользуйтесь **панелью сессии** (см. [ниже](#панель-сессии)).

::callout{icon="i-heroicons-information-circle" color="gray"}
Одновременно может записываться только одна сессия. Если уже идёт запись другой сессии, в окне появляется **Идёт запись** с кнопкой **Открыть текущую сессию**. Сначала остановите ту сессию или нажмите **Запланировать**.
::

## Окно «Новая сессия»

Окно состоит из четырёх частей. Переходить между ними можно по панели шагов вверху. Часть **Шаблон** открыта всегда, остальные три раскрываются по нажатию.

### Шаблон

| Параметр | Что делает |
| --- | --- |
| **Карточки шаблонов** | [Шаблон сессии](/sessions/templates-and-skills) — это тип сессии, например *Встреча*, *1:1*, *Интервью* или *Голосовая заметка*. Он задаёт разделы итогов, инструкции для ИИ и настройки звука и участников по умолчанию. В окне показывается до пяти карточек, сначала закреплённые шаблоны, и на каждой указан источник звука. Если включённых шаблонов больше, нажмите **Ещё…**, чтобы найти любой из них по категориям, или **Управление шаблонами…** внизу этого списка, чтобы открыть настройки шаблонов. См. [какой шаблон выбирается первым](/sessions/templates-and-skills#с-какого-шаблона-начинается-сессия). При выборе шаблона ваши изменения его разделов, звука и участников сбрасываются. |
| **Разделы** | Разделы итогов, которые заполняет этот шаблон. Нажмите **Настроить**, чтобы включить или выключить разделы, или **Добавить раздел**, чтобы найти раздел из другого включённого шаблона и взять его. Эти изменения действуют только для этой сессии. Закончив, нажмите **Готово**. |
| **Звук** | **Микрофон** (ваш голос), **Системный звук** (звук, который воспроизводит компьютер, например собеседник в звонке) или **Микрофон + система** (оба источника; **Микрофон + системный звук** в разделе **Настройки → Голос**). |
| **Загрузить аудиофайл** | Создаёт сессию из готовой записи. См. [Импорт записей](/sessions/importing-recordings). |
| **Участники** | Сколько человек ожидается: **Только вы**, **Вы + 1**, **Несколько (2–4)** или **Много (5–8)**. Это помогает TalkBar различать голоса. |
| **Участников в начале** | Ожидаемые голоса в виде полей, первое из которых — **Вы**. Кнопки рядом добавляют и убирают поля. Нажмите на поле, чтобы ввести имя, или введите `@`, чтобы выбрать сохранённого человека. Новые голоса занимают свободные поля по порядку; позже участников можно переименовать или объединить. |
| **ИИ** | Какая ИИ-модель ведёт хронологию и подводит итоги. **По умолчанию** использует настроенную вами модель; откройте меню, чтобы выбрать другую модель для этой сессии. **Приватный ИИ** выполняет сессию только на встроенных локальных моделях (см. ниже). |
| **Темы** и **Источник** | Отметьте сессию [темами](/knowledge/topics-and-keywords) и укажите, откуда она, например ссылку на видео или встречу. |

Если значения **Звук** или **Участники** отличаются от предложенных шаблоном, кнопка **Вернуть как в шаблоне** восстановит их.

::callout{icon="i-heroicons-light-bulb" color="primary"}
Для режима **Много (5–8)** TalkBar нужна более крупная модель определения голосов. Если она не скачана, окно сообщит об этом и предложит **Скачать**. Без неё TalkBar разделяет не больше 4 участников. См. [Участники](/voice/speakers).
::

#### Приватный ИИ для одной сессии

Выберите **Приватный ИИ** в строке **ИИ**, чтобы ИИ этой сессии работал только на вашем компьютере. Заголовок окна сменится на **Эта сессия будет работать на приватном ИИ**, а на экране записи появится значок щита. Эта настройка закрепляется за сессией навсегда: итоги для неё всегда подводят встроенные локальные модели.

Для режима **Приватный ИИ** нужна скачанная встроенная локальная модель. Если её нет, добавьте её в разделе **Настройки → Локальный ИИ**. См. [Приватный режим ИИ](/ai/private-ai-mode) и [Локальные модели](/ai/local-models).

### Проект и серия

| Параметр | Что делает |
| --- | --- |
| **Проект** | Относит сессию к [проекту](/knowledge/projects). Чтобы создать проект, выберите **Новый проект…**. |
| **Серия** | Добавляет сессию в [серию сессий](/sessions/series). Чтобы создать серию, выберите **Новая серия…**. |
| **По умолчанию** | Появляется после выбора серии. **Сохранить как настройки серии** делает выбранное в окне отправной точкой для следующих сессий серии. **Из последней** и **Копировать из прошлой сессии…** копируют настройки сессии, которая уже есть в серии. |

### Подготовка и контекст

Прикрепите то, что ИИ должен учитывать во время сессии. Эти материалы можно читать во время записи; они помогают с подсказками и итогами.

| Параметр | Что делает |
| --- | --- |
| **Люди** | **Добавить людей** из ваших контактов. Они прикрепляются к сессии как контекст. |
| **База знаний** | **Добавить карточки** из ваших [карточек знаний](/knowledge/knowledge-cards). Они подсвечиваются, когда о них заходит речь. |
| **Документы** | **Добавить документы** из [библиотеки документов](/knowledge/documents). |
| **Подготовить** / **Открыть подготовку** | Открывает полную страницу подготовки с заметками, поиском по документам и черновиками на проверку. Если сессия ещё не запланирована, **Подготовить** сначала сохраняет её как подготовку. См. [Подготовка к сессии](/sessions/scheduling-and-preparing#подготовка-к-сессии). |

### ИИ и конфиденциальность

| Параметр | Что делает | По умолчанию |
| --- | --- | --- |
| **Язык итогов** | Язык итогов, хронологии и названия, предложенного ИИ. **Авто** следует языку речи. Нажмите **Ещё…**, чтобы выбрать один из 16 языков. | Авто |
| **Длина итогов** | **Кратко**, **Стандартно** или **Подробно**. Влияет только на итоги, но не на хронологию. | Стандартно |
| **Конфиденциальность** | Что TalkBar может делать со знаниями из этой сессии. См. таблицу ниже. | Обычный |

Режимы в строке **Конфиденциальность**:

| Режим | Что происходит |
| --- | --- |
| **Обычный** | Подсказки во время записи, предложения для базы знаний и поиск работают. |
| **Только сессия** | Подсказки во время записи работают, но позже эта сессия не попадёт в поиск и предложения. Добавленные вами карточки остаются в этой сессии. |
| **Без автокарточек** | Во время сессии карточки не всплывают. «Спросить ИИ» и поиск работают; предложения для базы знаний выключены. |
| **Конфиденциальный** | Подсказки, «Спросить ИИ», предложения и поиск для этой сессии выключены. Добавленные вами карточки остаются в этой сессии. |

Режимы конфиденциальности никогда не мешают сохранить запись, транскрипт и итоги.

## Настройки по умолчанию

Внизу окна:

- **Сохранить по умолчанию** запоминает текущий выбор. В следующий раз окно заполнится им, если нет более конкретных настроек (например, собственных настроек серии или подготовленной сессии).
- **Сбросить настройки** возвращает окно к сохранённым настройкам по умолчанию.

Шаблон по умолчанию также можно выбрать в разделе **Настройки → Общие → Параметры сессий**. См. [Общие настройки](/settings/general).

## Начать, подготовить или запланировать

| Кнопка | Что делает |
| --- | --- |
| **Начать сессию** | Сразу начинает запись и открывает [экран записи](/sessions/recording). |
| **Подготовить** | Сохраняет настройки как сессию, к которой нужно подготовиться, и открывает её страницу подготовки. |
| **Запланировать** | Превращает настройки в запланированную сессию. См. [Планирование и подготовка](/sessions/scheduling-and-preparing). |
| **Отмена** | Закрывает окно, не начиная сессию. |

Если кнопка **Начать сессию** недоступна, найдите одно из этих уведомлений:

- **Модель распознавания речи не готова.** Скачайте модель речи или нажмите **Открыть настройки голоса**. См. [Настройки голоса](/settings/voice).
- **Идёт импорт аудио** — дождитесь его окончания или запланируйте сессию на потом.
- **Идёт запись** — записывается другая сессия.
- На бесплатном тарифе в рабочем пространстве исчерпан лимит сессий. Переместите старую сессию в корзину, чтобы освободить место. См. [Ограничения тарифа](/sessions/overview#ограничения-тарифа).

## Панель сессии

Панель сессии — это небольшое окно поверх других приложений, по умолчанию в правом верхнем углу экрана. Нажмите `Ctrl+Alt+B`, чтобы показать или скрыть её.

- Когда ничего не записывается, панель спрашивает **Начать сессию?** Выберите **Шаблон:** и **Источник:** (**Микрофон**, **Система** или **Микрофон + система**), затем нажмите **Начать сессию**.
- Во время записи панель превращается в компактное окно текущей сессии. См. [Панель сессии во время записи](/sessions/recording#панель-сессии).

### Распознавание сессий

TalkBar может заметить, что рядом с микрофоном начался разговор, и предложить его записать. Тогда на панели сессии появляется **Похоже на разговор — начать сессию?** и короткий фрагмент услышанного. Нажмите **Начать сессию**, **Пропустить**, чтобы на время отключить распознавание, или выключите распознавание прямо на панели.

Распознавание включено по умолчанию. Его, длительность пропуска, а также сочетание клавиш, положение панели и число строк транскрипта на ней можно изменить в разделе **Настройки → Общие → Распознавание сессий**. Распознавание никогда не начинает запись само, и ничего из услышанного не сохраняется.
