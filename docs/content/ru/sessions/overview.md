**Сессия** — это одна записанная встреча, звонок или разговор. TalkBar записывает звук, по ходу разговора ведёт транскрипт с разбивкой по участникам, пополняет хронологию, а после окончания сессии подводит итоги. Сессии хранятся на вашем компьютере; данные получают только те ИИ-провайдеры и каналы, которые вы сами настроили.

Если вы ещё не записывали сессии, начните со страницы [Первая сессия](/getting-started/first-session).

## Что содержит сессия

| Часть | Что это |
| --- | --- |
| Транскрипт | Что было сказано — по участникам и со временем. |
| Хронология | Короткие заметки ИИ, которые появляются во время записи, по умолчанию каждые 10 секунд. |
| Итоги | Окончательный текст, разбитый на разделы [шаблона](/sessions/templates-and-skills) сессии. |
| Заметки | Ваша собственная заметка к сессии с форматированием. |
| Задачи | Задачи, напоминания, вопросы и решения из сессии. |
| Документы | Файлы, которые вы прикрепили для справки. |
| База знаний | [Карточки знаний](/knowledge/knowledge-cards), прикреплённые к сессии или прозвучавшие в ней. |
| Аудио | Сама запись, если вы её не удалили. |

## Список сессий

Откройте **Сессии** на боковой панели. На странице перечислены все сессии текущего рабочего пространства.

::screenshot{src="/screenshots/sessions/sessions-list.png" alt="Страница «Сессии» на вкладке «Все сессии»: вверху полоса «Скоро», вкладки «Все сессии», «Закреплённые» и «Корзина», кнопки сортировки и фильтров и несколько строк сессий в группах «Сегодня» и «Вчера»" caption="Список сессий"}
::

В верхней части страницы — кнопки других страниц сессий и основное действие:

- **Предстоящие** открывает календарь запланированных сессий. См. [Планирование и подготовка](/sessions/scheduling-and-preparing).
- **Серии** открывает ваши [серии сессий](/sessions/series).
- **Подготовить** показывает сессии, к которым вы готовитесь.
- **Начать сессию** открывает окно «Новая сессия». См. [Начало сессии](/sessions/starting-a-session).

Ниже, в полосе **Скоро**, показаны запланированные сессии на ближайшую неделю. У сессии, которая начнётся в ближайшие минуты, появляется кнопка **Начать**.

### Вкладки

| Вкладка | Что показывает |
| --- | --- |
| **Все сессии** | Все сессии, кроме тех, что в корзине. |
| **Закреплённые** | Только закреплённые вами сессии. |
| **Корзина** | Сессии, которые вы переместили в корзину. |

На вкладке **Все сессии** список разбит на группы:

- вверху — сессия, которая записывается сейчас;
- **Продолжите с того же места** — сессии, которые вы остановили, но ещё не завершили;
- **Закреплённые**, если включено **Закреплены сверху**;
- затем по группе на каждый день (**Сегодня**, **Вчера**, далее — даты).

### Сортировка, фильтры и поиск

- **Сортировка**: **Дата сессии** (по умолчанию), **Недавно изменённые** или **Название**. **Сбросить** возвращает сортировку по умолчанию.
- **Фильтры**: **Фильтр по серии**, **Фильтр по проекту**, **Фильтр по теме** и **Фильтр по слову**. Активные фильтры отображаются метками над списком; нажмите **×** на метке, чтобы убрать её, или **Сбросить фильтры**, чтобы убрать все сразу.
- **Поиск** ищет слова в названии сессии, проекте, серии, ключевых словах и именах участников. Должно совпасть каждое введённое слово. Если совпадение найдено в том, чего нет в строке, строка подсказывает, где именно, например **Участники:** и имя участника.

::callout{icon="i-heroicons-light-bulb" color="primary"}
Чтобы искать по транскриптам, итогам и заметкам всех сессий, воспользуйтесь поиском в строке заголовка или функцией [Спросить TalkBar](/chats-and-notes/ask-talkbar).
::

### Действия со строкой

Нажмите на строку, чтобы открыть сессию. В меню **⋮** каждой строки есть:

| Действие | Примечания |
| --- | --- |
| **Поделиться** | Только для завершённых сессий. См. [Ссылки для общего доступа](/sharing/share-links). |
| **Экспорт сессии** | Только для завершённых сессий. См. [Экспорт](/sharing/exports). |
| **Открыть** | Открывает сессию. |
| **Закрепить** / **Открепить** | Закреплённые сессии показываются на вкладке **Закреплённые**. |
| **Добавить в серию…** / **Переместить в серию…** | Добавляет сессию в [серию](/sessions/series). |
| **Убрать из серии** | Показывается, если сессия входит в серию. |
| **В корзину** | Недоступно, пока идёт запись сессии. |

У остановленных, но не завершённых сессий прямо в строке есть кнопки **Продолжить** и **Завершить**.

## Статусы сессий

Сессия проходит через несколько состояний. Для каждого состояния, кроме завершённого, в списке показывается метка.

| Метка | Что означает |
| --- | --- |
| **Запись** | Сессия записывается прямо сейчас. Одновременно может записываться только одна сессия. |
| **ПАУЗА** | Запись на паузе. Пока вы её не возобновите, ничего не записывается. |
| **Ожидание звука** | Все источники звука выключены или недоступны, поэтому ничего не записывается. |
| **Импорт** | TalkBar создаёт сессию из [аудиофайла](/sessions/importing-recordings). |
| **Идёт** | Вы остановили запись, но не завершили сессию. В неё ещё можно **продолжить** запись. |
| **Прервана** | Запись неожиданно остановилась, например при закрытии TalkBar или выключении компьютера. См. [Прерванные сессии](/sessions/recording#прерванные-сессии). |
| *(без метки)* | **Завершена.** Сессия закончена и открывается на [странице подробностей](/sessions/session-details). |

Когда вы нажимаете **Стоп**, сессия получает статус **Идёт**: TalkBar подводит итоги, а вы по-прежнему можете дописать запись в ту же сессию. Когда вы нажимаете **Завершить сессию**, она закрывается окончательно. Завершённую сессию нельзя открыть снова, но можно записать связанное **продолжение**. См. [После остановки](/sessions/recording#после-остановки).

## Закреплённые сессии

Закрепите сессию через меню её строки, чтобы она всегда была под рукой. Включите **Закреплены сверху** на вкладке **Все сессии**, чтобы закреплённые сессии шли над остальными, или перейдите на вкладку **Закреплённые**, чтобы видеть только их. Автоматическое хранение сессий никогда не перемещает закреплённые сессии в корзину.

## Корзина

**В корзину** просит подтвердить действие, а затем перемещает сессию на вкладку **Корзина**. Оттуда её можно восстановить.

На вкладке **Корзина**:

- **Восстановить** возвращает сессию в список.
- **Удалить** удаляет одну сессию навсегда после подтверждения.
- **Очистить корзину** навсегда удаляет все сессии в корзине.

При окончательном удалении стираются транскрипт, аудио, файлы сессии и данные, которые относятся только к ней. Карточки знаний, задачи и черновики на проверку остаются — они просто теряют связь с сессией.

::callout{icon="i-heroicons-exclamation-triangle" color="amber"}
Окончательное удаление нельзя отменить.
::

Две настройки в разделе **Настройки → Общие** делают это за вас:

| Настройка | Что делает | По умолчанию |
| --- | --- | --- |
| **Очистка корзины** → **Автоматически очищать корзину** | Навсегда удаляет сессии и заметки, которые пролежали в корзине дольше срока **Хранить в корзине**. | Включено, 30 дней |
| **Хранение сессий** → **Автоматически перемещать старые сессии в корзину** | Перемещает сессии в корзину по количеству (**Хранить не более**) или по возрасту (**Перемещать сессии старше**). Закреплённые сессии и идущие записи не перемещаются никогда. Выполняется для каждого рабочего пространства при запуске TalkBar. | Выключено |

## Ограничения тарифа

На тарифе **Бесплатный**:

- В рабочем пространстве можно хранить до **20 сессий**; предупреждения TalkBar начинает показывать с 15. Сессии в корзине не учитываются, поэтому перемещение старой сессии в корзину освобождает место. Когда лимит исчерпан, новую сессию нельзя ни записать, ни импортировать, но все существующие сессии остаются полностью доступны.
- Каждая сессия может длиться до **30 минут**. TalkBar предупреждает о приближении лимита, затем останавливает запись и сохраняет сессию вместе с итогами.

На платных тарифах число хранимых сессий и длительность записи не ограничены. См. [Тарифы и лицензия](/data/plans-and-license).
