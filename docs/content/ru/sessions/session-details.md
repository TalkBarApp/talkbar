Завершённая сессия открывается на своей странице подробностей. Здесь можно читать и редактировать итоги, проверять транскрипт, разбирать задачи, а также делиться сессией, экспортировать её или записать продолжение.

::callout{icon="i-heroicons-information-circle" color="gray"}
Сессии, которые ещё записываются, остановлены, но не завершены, или прерваны, открываются на [экране записи](/sessions/recording). Чтобы завершить такую сессию, нажмите там **Завершить сессию**.
::

## Верхняя панель

В верхней панели показаны:

- название **шаблона** — оно же меню для смены шаблона (см. [Смена шаблона](#смена-шаблона));
- дата и время, длительность сессии и её происхождение (**Записано на устройстве** или **Из аудиофайла**);
- **название**: нажмите на него или на карандаш, чтобы переименовать; нажмите на кнопку со звёздочками, чтобы **Создать название с ИИ**;
- **темы**: добавляйте и убирайте [темы](/knowledge/topics-and-keywords) с помощью выбора тем.

Кнопки верхней панели:

| Кнопка | Что делает |
| --- | --- |
| **Спросить ИИ** | Открывает чат об этой сессии. См. [Спросить TalkBar](/chats-and-notes/ask-talkbar). |
| **Поделиться** | Открывает окно общего доступа. В его меню есть **Опубликовать ссылку**, **Отправить материал** и, когда ссылки уже есть, **Мои ссылки**. См. [Ссылки для общего доступа](/sharing/share-links). |
| **⋮** (**Действия с сессией**) | Другие действия — они перечислены ниже. |

Меню **⋮**:

| Действие | Что делает |
| --- | --- |
| **Записать продолжение** | Сразу начинает запись связанного продолжения с той же серией, проектом, названием и шаблоном. |
| **Назначить продолжение** | Открывает окно планирования, где уже указаны серия, проект и название. |
| **Найти знания** | Ищет в этой сессии карточки знаний. Скрыто, если режим конфиденциальности сессии этого не разрешает. См. [Проверка и поиск знаний](/knowledge/review-and-scans). |
| **Экспорт сессии** | Экспортирует сессию. После первого экспорта превращается в подменю с пунктами **Экспортировать снова…**, открытием экспортированных файлов и **История экспорта**. См. [Экспорт](/sharing/exports). |
| **Добавить источник** / **Изменить источник** | Указывает, откуда сессия, — название и необязательная ссылка. |
| **Аудиоплеер** | **Показать плеер** или **Скрыть плеер**, **Экспорт аудио** и **Удалить аудио**. Показывается, только если у сессии есть аудио. |
| **В корзину** | Перемещает сессию в корзину после подтверждения. |

Чтобы закрепить сессию, воспользуйтесь меню её строки в [списке сессий](/sessions/overview#действия-со-строкой).

## Аудиоплеер

Плеер находится под верхней панелью. В нём можно воспроизводить запись, перематывать по звуковой волне и переходить к сменам участников. Если сессия записана в несколько приёмов (после **Продолжить сессию**), плеер показывает, какая запись сейчас играет.

Нажмите на время у любой строки транскрипта, чтобы **Воспроизвести отсюда**. Результаты поиска и ссылки из итогов или чатов тоже переходят к нужному моменту.

**Скрыть плеер** скрывает его во всех сессиях; **Показать плеер** возвращает его.

## Поиск по сессии

Поле **Поиск по сессии…** ищет по транскрипту, хронологии, задачам, решениям, вопросам и карточкам знаний этой сессии и переходит к каждому совпадению.

## Вкладки

| Вкладка | Что показывает |
| --- | --- |
| **Обзор** | Статистику, итоги, участников, проект и серию. |
| **Задачи** | Задачи, напоминания, вопросы и решения с их числом. |
| **Транскрипт** | Полный транскрипт и хронологию. |
| **Заметки** | Вашу заметку к сессии. |
| **Документы** | Файлы, прикреплённые к сессии. |
| **База знаний** | Карточки знаний сессии с их числом. |

## Обзор

### Статистика

Плитки вверху показывают **Длительность**, **Участники** (те, кто действительно говорил), **Реплики** и **Упоминания** (карточки и задачи, прозвучавшие в разговоре). Для тренировочных шаблонов, например *Репетиция выступления*, вместо них показываются **Слов в минуту** и **Самая длинная пауза**.

### Итоги

Итоги находятся в карточке **Итоги сессии**. Сначала идут обзор и ключевые выводы, затем разделы [шаблона](/sessions/templates-and-skills) сессии.

У каждого раздела есть меню **⋮**:

| Действие | Что делает |
| --- | --- |
| **Сделать задачей** | Отмечает текст раздела как задачу. |
| **Копировать текст** | Копирует раздел. |
| **Добавить закладку** | Добавляет закладку на раздел. |
| **Добавить в заметку** | Добавляет раздел в заметку к сессии. |
| **Пересоздать раздел** | Переписывает только этот раздел. Если вы его редактировали, сначала спрашивает. |
| **Изменить текст** | Позволяет отредактировать раздел на месте. |
| **Удалить раздел** | Убирает раздел из итогов. |

Меню **ИИ** карточки меняет то, как подводятся итоги:

| Параметр | Что делает |
| --- | --- |
| **Разделы итогов** | Показывает, сколько разделов включено, например *Разделов: 5 из 6*. Включайте и выключайте разделы или выберите **Добавить раздел**, чтобы взять раздел из другого включённого шаблона. |
| **Язык итогов** | Язык итогов. **Сбросить на «Авто»** — следовать языку речи. |
| **Длина итогов** | **Кратко**, **Стандартно** или **Подробно**. Точкой отмечены длины, для которых итоги в этой сессии уже подведены, — они переключаются мгновенно. |
| **ИИ-модель** | Модель, которая подводит эти итоги. **Вернуть по умолчанию** возвращает настроенную вами модель. |
| **Подвести итоги заново** | Заново подводит все итоги с текущими настройками и шаблоном. |

Изменённые язык, длина или модель вступают в силу только после повторного подведения итогов. Карточка показывает **Новые настройки итогов применятся, когда вы создадите их заново.** с кнопками **Создать заново** и **Отмена**. Повторное подведение итогов заменяет ваши правки, поэтому TalkBar сначала спрашивает.

Внизу карточки показано, когда итоги были подведены или изменены, какая модель их подвела и сколько времени это заняло. Там же есть **Поделиться итогами**, **Копировать как текст**, **Копировать как Markdown** и **Подвести итоги заново**.

Если у сессии ещё нет итогов, нажмите **Подвести итоги**.

### Смена шаблона

Откройте название шаблона в верхней панели или в карточке итогов и выберите другой шаблон. TalkBar спросит **Перейти на «*шаблон*»?**:

- **Только сменить** меняет шаблон, но оставляет текущие итоги как есть.
- **Сменить и пересоздать** меняет шаблон и заново подводит итоги по его разделам. Если вы редактировали итоги, TalkBar предупредит, что правки будут заменены.

Разделы, которые вы добавили в эту сессию, сохраняются.

### Боковые панели

| Панель | Что делает |
| --- | --- |
| **Участники** | Все участники по убыванию времени разговора и их доля в разговоре. Нажмите на участника, чтобы переименовать или изменить его (см. [Участники](#участники)). |
| **Источник** | Откуда сессия. Чтобы изменить, нажмите **Изменить источник**. |
| **Проект** | [Проект](/knowledge/projects) сессии. **Сменить проект** переносит сессию; заодно можно перенести в новый проект её карточки знаний. |
| **Серия** | **Добавить в серию**, а для сессии в серии — **Открыть серию**, **Сменить серию…** и **Убрать из серии**. Показывает место сессии в серии и следующую сессию. См. [Серии](/sessions/series). |
| **По расписанию** | Для запланированной сессии: запланированные время и длительность, началась ли она вовремя, и **Назначить продолжение**. |
| **Поиск знаний** | Искались ли в сессии знания и что было найдено, с кнопками **Сканировать**, **Пересканировать** или **Открыть проверку**. |
| **Последние изменения** | История правок сессии. |

Если у сессии есть временные воспоминания, баннер предложит **Оставить все** или **Удалить все**.

## Участники

Нажмите на метку участника — на панели **Участники** или в транскрипте, — чтобы открыть его меню:

| Параметр | Что делает |
| --- | --- |
| **Переименовать голос** | Даёт участнику имя. Введите `@`, чтобы связать участника с сохранённым человеком. |
| **Ведущий сессии** | Отмечает человека, который ведёт сессию. |
| **Это я** | Отмечает участника как вас. |
| **Игнорировать участника** | Скрывает реплики участника и не передаёт их текст ИИ. В аудио остаются все голоса. |
| **Метка** | Задаёт участнику метку роли, например *Клиент* или *Руководитель*. **Управление метками** открывает **Настройки → Голос → Участники**. |
| **Объединить участников…** | Переносит всю речь этого участника к другому, если TalkBar разделил одного человека на двух. |
| **Цвет** | Меняет цвет участника. |

Имена попадают в транскрипт и итоги. Как TalkBar распознаёт голоса, читайте на странице [Участники](/voice/speakers).

## Транскрипт

На вкладке **Транскрипт** два вида: **Транскрипт** (все реплики) и **Хронология** (заметки, сделанные во время записи).

Нажмите на строку правой кнопкой мыши или откройте её меню **⋮**:

| Действие | Что делает |
| --- | --- |
| **Сделать задачей** | Отмечает строку как задачу. |
| **Участник** → **Назначить…** | Передаёт строку другому участнику; можно также ввести `@`, чтобы выбрать человека. |
| **Участник** → **Объединить с предыдущей** | Присоединяет строку к предыдущей. |
| **Копировать текст** | Копирует строку. |
| **Добавить закладку** | Добавляет закладку на этот момент. |
| **Добавить в заметку** | Добавляет строку в заметку к сессии. |
| **Изменить текст** | Позволяет исправить формулировку. |
| **Удалить** | Удаляет строку. Это нельзя отменить. |

Меню **Вид** переключает **Классический вид**, **С аватарами** и **Как в чате**, задаёт порядок и открывает **Прошлые транскрипты**. Если сессия переводилась, показываются и оригинал, и перевод.

### Улучшить транскрипт

**Улучшить транскрипт** заново обрабатывает сохранённую запись более точной моделью распознавания речи на вашем компьютере, чтобы улучшить текст и разделение участников. Функция доступна для завершённых сессий, у которых ещё есть аудио.

1. Нажмите **Улучшить транскрипт**, выберите **Модель улучшения** и **Язык речи** и запустите обработку. Если модели нет, TalkBar предложит её скачать.
2. Когда обработка закончится, проверьте результат в карточке **Улучшенный транскрипт готов к проверке**. **Показать предпросмотр** показывает новый текст.
3. Если некоторые участники не совпали, сопоставьте каждого с существующим участником или оставьте его новым участником, затем нажмите **Применить сопоставление**.
4. Нажмите **Заменить транскрипт сессии**, чтобы использовать новую версию, или **Удалить улучшенный транскрипт**, чтобы оставить старую.

Старый транскрипт остаётся в разделе **Вид → Прошлые транскрипты**. После замены подведите итоги заново, если хотите, чтобы они учитывали новый текст.

## Задачи

На вкладке **Задачи** собрано всё, что нужно сделать или запомнить после сессии: задачи, напоминания, вопросы и решения. Переключайтесь между **Все**, **Эта встреча** и **Взятые** (задачи, перенесённые из прошлых сессий или подготовки).

- Выберите вид **Таблица** или **Доска** и фильтруйте задачи по статусу, типу или источнику.
- Нажмите **Добавить задачу**, чтобы создать задачу, или **Добавить существующую задачу**, чтобы взять уже существующую.
- Отмечайте задачи выполненными, отвечайте на вопросы и отмечайте решения как заменённые.
- В меню задачи её можно **Изменить**, **Преобразовать** в другой тип, открыть её источник в транскрипте или итогах или убрать её.

::callout{icon="i-heroicons-exclamation-triangle" color="amber"}
Если убрать созданную вами задачу, она удаляется навсегда — задачи не попадают в корзину. Если убрать задачу из итогов, она скрывается и не появится снова при повторном подведении итогов.
::

Как задачи работают в разных сессиях и проектах, читайте на странице [Задачи](/knowledge/action-items).

## Заметки, документы и база знаний

- **Заметки**: ваша заметка к сессии с форматированием. Над ней перечислены другие заметки, которые ссылаются на эту сессию. См. [Заметки](/chats-and-notes/notes).
- **Документы**: прикрепляйте файлы через **Загрузить файл**, **Из библиотеки документов** или **Из заметок** и ищите по их содержимому. **Убрать из сессии** оставляет документ в библиотеке. См. [Документы](/knowledge/documents).
- **База знаний**: база знаний сессии и черновики карточек. Выберите **Новая карточка**, **Извлечь карточки** или **Добавить из базы знаний**. В блоке **Прозвучало в разговоре** перечислены карточки, упомянутые в сессии, со ссылками на нужный момент. См. [Карточки знаний](/knowledge/knowledge-cards).

## Навыки

Навыки — это готовые запросы к ИИ, которые можно использовать в чате. Чтобы применить навык к этой сессии, нажмите **Спросить ИИ**, затем в чате нажмите **Навыки** и выберите нужный, например *Письмо по итогам* или *Краткий пересказ*. Результат появится в ответе в чате. См. [Шаблоны и навыки](/sessions/templates-and-skills#навыки).

## Аудио и хранение

**Удалить аудио** (в меню **⋮ → Аудиоплеер**) навсегда удаляет запись сессии после того, как вы введёте `DELETE` для подтверждения. Транскрипт, заметки и итоги остаются, но воспроизведение и **Улучшить транскрипт** становятся недоступны. Аудио нельзя удалить, пока сессия записывается, её аудио ещё сохраняется или транскрипт улучшается.

**Экспорт аудио** сохраняет запись в формате **OPUS (оригинал)**, **MP4 (AAC)**, **MP3** или **WAV**.

Чтобы автоматически удалять аудио из каждой новой сессии, включите **Удалять аудио после окончания сессии** в разделе **Настройки → Голос → Запись → Сохранённая запись** (по умолчанию выключено). В том же разделе задаётся **Качество** записи. Настройки, которая хранила бы аудио заданное число дней, в TalkBar нет; чтобы убирать старые сессии, используйте **Хранение сессий** (см. [Корзина](/sessions/overview#корзина)).

## Перемещение, переименование и удаление в корзину

| Чтобы… | Сделайте так |
| --- | --- |
| Переименовать | Нажмите на название. |
| Перенести в проект | Панель **Проект** → **Сменить проект**. |
| Добавить в серию или перенести в другую | Панель **Серия**. |
| Закрепить | Воспользуйтесь меню строки сессии в списке сессий. |
| Переместить в корзину | **⋮ → В корзину**. Восстановить её можно в разделе **Сессии → Корзина**. |
