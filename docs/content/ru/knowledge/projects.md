**Проект** объединяет всё, что относится к одной работе, например к клиенту, сделке, продукту или найму: сессии, документы, карточки знаний, людей, компании и задачи. Проекты необязательны. Пользоваться TalkBar можно и без них.

## Страница «Проекты»

Нажмите **Проекты** на боковой панели. Под этим пунктом также видно до пяти ваших проектов, сначала закреплённые, так что можно сразу перейти к нужному. Если проектов больше, **Все проекты** открывает эту страницу. Стрелка в строке проекта показывает его сессии.

| Элемент | Что делает |
| --- | --- |
| **Новый проект** | Создаёт проект. |
| **Управлять** | Открывает раздел **Настройки → Проекты**. См. [Настройки проектов, тем и ключевых слов](/settings/projects-and-topics). |
| **По компаниям** / **Без группировки** | Группирует проекты по компаниям, к которым они привязаны. Закреплённые проекты остаются вверху, вне групп, а проекты без компании попадают в **Без компании**. |
| Закрепление | **Закрепить проект** держит проект вверху списка и на боковой панели. |
| Меню ⋮ или правый клик по карточке | **Закрепить проект** или **Открепить проект**, **Изменить проект** и **В корзину**. |

## Создание проекта

Нажмите **Новый проект** и заполните поля:

| Поле | Что задаёт |
| --- | --- |
| Значок и цвет | Как проект выглядит на боковой панели и в списках. |
| **Название** | Название проекта. |
| **Тип** | Клиент, Контракт, Регулярный, Внутренний, Личное, Исследование, Продукт, Продажи, Найм, Обучение, Мероприятие или Поддержка. |
| Логотип | Изображение на странице проекта. |
| **Организация** | Компания, для которой ведётся проект. |
| **Шаблон сессии по умолчанию** | Шаблон, с которым начинаются новые сессии в этом проекте. |
| **Ссылки** | Ссылки на документы, доски или репозитории, где идёт работа над проектом. |
| **Описание** | О чём проект. |

Нажмите **Создать проект**. Позже эти данные можно поменять кнопкой **Изменить** на странице проекта. Чтобы переименовать проект, нажмите на его название на странице проекта. Название не может быть пустым.

## Лимит проектов по тарифам

Тариф определяет, сколько проектов может быть в каждом рабочем пространстве. Проекты в корзине не учитываются.

| Тариф | Проектов в рабочем пространстве |
| --- | --- |
| Бесплатный | 1 |
| Personal | 1 |
| Plus | Без ограничений |
| Pro | Без ограничений |
| Business | Без ограничений |

Когда лимит исчерпан, вместо создания проекта или его восстановления из корзины TalkBar показывает ограничения вашего тарифа. См. [Тарифы и лицензия](/data/plans-and-license).

## Страница проекта

Вверху страницы проекта видны его название, тип, описание и ссылки, а также предстоящие запланированные сессии. У длинного описания есть **Показать ещё**. У закреплённого проекта значок рядом с названием открепляет его. Кнопки:

| Кнопка | Что делает |
| --- | --- |
| **Экспорт** | Экспортирует сессии проекта. См. [Экспорт](/sharing/exports). |
| **Изменить** | Меняет данные проекта. |
| **Добавить** | **Перенести сессии** в проект или добавить элемент: **Задача**, **Карточка знаний**, **Извлечь карточки**, **Документ**, **Контакт** или **Компания**. Каждый пункт открывает нужную вкладку или окно. **Извлечь карточки** затем открывает вкладку **Проверка**. |
| **Новая сессия** | Начинает запись сессии, которая сохранится в этом проекте. |

### Вкладки проекта

| Вкладка | Что показывает |
| --- | --- |
| **Обзор** | Закреплённые и недавние сессии, закреплённые карточки знаний и до пяти открытых задач со сроками. Пока сессий нет, здесь есть кнопки **Новая сессия** и **Перенести сессии**. |
| **Задачи** | Задачи, решения и вопросы из всех сессий проекта, а также элементы, добавленные в сам проект. См. [Задачи](/knowledge/action-items). |
| **Сессии** | Сессии проекта. Переключайтесь между **Все** и **Закреплённые**, фильтруйте по теме или ключевому слову и сортируйте: **Недавно изменённые**, **Дата сессии** или **Название**. |
| **Карточки знаний** | Карточки, сохранённые в проекте. См. [Карточки знаний](/knowledge/knowledge-cards). |
| **Документы** | Документы, сохранённые в проекте. См. [Документы](/knowledge/documents). |
| **Люди** | Люди, добавленные в проект, и участники его сессий. |
| **Компании** | Компании, добавленные в проект, а также компании его людей и участников сессий. |
| **Проверка** | Предложения для базы знаний из сессий и документов проекта. См. [Проверка и поиск знаний](/knowledge/review-and-scans). |

Вкладки «Карточки знаний», «Документы», «Люди», «Компании» и «Проверка» работают так же, как одноимённые вкладки в разделе **База знаний**, только в пределах этого проекта.

## Как сохранить элементы в проект

| Элемент | Как сохранить в проект |
| --- | --- |
| Новая сессия | Выберите проект, когда начинаете сессию, или нажмите **Новая сессия** на странице проекта. |
| Существующая сессия | На странице проекта выберите **Добавить** → **Перенести сессии**. Или укажите проект в подробностях сессии. |
| Карточка знаний | Выберите проект, когда пишете карточку, или выберите **Перенести** → **Проект** в карточке. |
| Документ | Выберите проект в поле **Сохранить в** при импорте или выберите **Перенести** для документа. |
| Человек или компания | **Добавить в** → **Проект** в их карточке. |
| Заметка | Привяжите заметку к проекту в её связях. См. [Заметки](/chats-and-notes/notes). |

Серию сессий тоже можно сохранить в проект. См. [Серии сессий](/sessions/series).

### Как перенести сессии в проект

1. На странице проекта выберите **Добавить** → **Перенести сессии**.
2. Отметьте сессии. В каждой строке видно, в каком проекте сессия сейчас или что она **Без проекта**. Сессий, которые уже в этом проекте, в списке нет.
3. Оставьте включённым **Также перенести карточки знаний из этой сессии**, чтобы их карточки перешли вместе с ними. Параметр включён по умолчанию и показывает, сколько карточек будет перенесено.
4. Нажмите **Перенести** и подтвердите.

У сессий сохранятся транскрипты, итоги и задачи. Изменится только проект. Чтобы убрать сессию из проекта, смените проект в подробностях сессии.

## Чат о проекте

В чате откройте **Источник ответов** и выберите **Только проект**, чтобы получать ответы из сессий, заметок, документов и карточек одного проекта. См. [Спросить TalkBar](/chats-and-notes/ask-talkbar).

## Перемещение проекта в корзину

В меню проекта (на странице «Проекты» или в разделе **Настройки → Проекты**) выберите **В корзину**. Проект исчезнет из списков выбора и с боковой панели. Его сессии, документы и карточки знаний сохраняются, пока вы не удалите проект безвозвратно в разделе **Удалённые проекты** в **Настройках → Проекты**. Опубликованные ссылки на сессии продолжают работать.

В разделе **Удалённые проекты** проект можно **Восстановить** или удалить безвозвратно. При безвозвратном удалении можно выбрать **Удалить всё** или **Оставить содержимое**. См. [Настройки проектов, тем и ключевых слов](/settings/projects-and-topics#удалённые-проекты).
