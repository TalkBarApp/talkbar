**Карточка знаний** — это один факт, который TalkBar хранит для вас: решение, предпочтение, обязательство, подробность о человеке или проекте. ИИ использует одобренные карточки, когда отвечает в чатах, готовит сессии и показывает контекст во время записи.

## Раздел «База знаний»

Откройте **База знаний** на боковой панели. На странице шесть вкладок:

| Вкладка | Что на ней |
| --- | --- |
| **Карточки знаний** | Ваши карточки знаний. Эта страница. |
| **Документы** | Импортированные файлы. См. [Документы](/knowledge/documents). |
| **Люди** | Контакты и участники сессий. См. [Люди и компании](/knowledge/people-and-companies). |
| **Компании** | Организации. См. [Люди и компании](/knowledge/people-and-companies). |
| **Задачи** | Задачи, решения и вопросы. См. [Задачи](/knowledge/action-items). |
| **Проверка** | Предложения, которые ждут вашего одобрения. Значок показывает, сколько их. См. [Проверка и поиск знаний](/knowledge/review-and-scans). |

Под пунктом **База знаний** на боковой панели можно закрепить ярлыки вкладок базы знаний (только значки). Включите их в разделе **Настройки → Общие → Внешний вид → Ярлыки базы знаний**. По умолчанию все они выключены.

## Что показывает карточка

На каждой карточке есть:

- **Название** и **подробности** — сам факт.
- **Категория** — тип карточки (см. ниже).
- **Источник** — откуда взялась карточка, например **Добавлено вами**, **Поиск знаний**, **Извлечено после сессии** или **Импорт из документа**.
- Дата **Подтверждено** — когда вы в последний раз подтвердили, что карточка ещё верна.
- Булавка, если карточка закреплена.

Нажмите на карточку, чтобы открыть её. В панели карточки есть такие разделы:

| Раздел | Что показывает |
| --- | --- |
| **Источник** | Сессия, документ или другой источник, из которого взята карточка, со ссылкой на него. У карточек, которые вы написали сами, источника нет. Если документ-источник позже изменился, на карточке появится надпись **Источник изменился после создания карточки.** |
| **Привязка** | Проект, в котором хранится карточка, или **Общее**. |
| **О карточке** | Люди, компании, проекты и документы, к которым относится карточка. **Привязать…** добавляет ещё один, **Сделать основным** выбирает главный. |
| **Связанные** | Связи с другими элементами базы знаний. **Добавить связь** связывает карточку с другим элементом и позволяет указать причину. Если убрать связь, удаляется только она. |
| **История** | Все изменения карточки, описанные простыми словами. |

Если эту карточку заменила более новая, на ней появится надпись **Заменена более новой карточкой знаний** со ссылкой.

## Типы карточек

У каждой карточки есть категория. Встроенные типы в TalkBar:

| Тип | Для чего |
| --- | --- |
| **Факт** | То, что верно. |
| **Предпочтение** | Как человек предпочитает работать. |
| **Решение** | То, что было решено. |
| **Обязательство** | То, что кто-то пообещал. |
| **Риск** | То, что может пойти не так. |
| **Открытый вопрос** | То, на что ещё нет ответа. |
| **Отношения** | Контекст о том, как связаны люди или компании. |
| **Указание** | Постоянное указание, которое TalkBar должен учитывать. |
| **Ключевой момент** | Важный момент, который стоит запомнить. |
| **Условие договора** | Условие из соглашения. |
| **Детали цены** | Цена, скидка или условия оплаты. |
| **Технические детали** | Технический факт или характеристика. |

Карточки с типом, который TalkBar не распознаёт, отображаются как **Другое**.

Можно добавить и свои категории. Откройте фильтры (**Другие фильтры**), нажмите **Категория** и в диалоге **Категории** выберите **Новая категория**. В этом же диалоге свои категории можно переименовать или удалить.

## Вкладки статусов

Карточки сгруппированы по статусу. Вкладка **Одобрено** видна всегда. Остальные вкладки включаются и выключаются в меню **Фильтр по виду** рядом с вкладками. **Устарело** и **В архиве** включены по умолчанию.

| Вкладка | Что на ней |
| --- | --- |
| **Одобрено** | Карточки, которые использует ИИ. **Закреплённые сверху** показывает закреплённые карточки первыми. |
| **Закреплённые** | Одобренные карточки, которые вы закрепили. В подсказках во время записи закреплённые карточки стоят выше. |
| **Нужна проверка** | Одобренные карточки, которые давно не подтверждались. **Подтвердить все** отмечает их все как по-прежнему верные. |
| **Устарело** | Карточки, которые вы отметили как устаревшие. Возможно, они уже неверны. |
| **В архиве** | Карточки, которые вы отправили в архив. Они скрыты из поиска, но хранятся здесь. |

Чтобы сохранить выбор вкладок, выберите **Сделать основным** в меню **Фильтр по виду**.

::callout{icon="i-heroicons-information-circle" color="gray"}
**Нужна проверка** — это не то же самое, что вкладка **Проверка**. В **Нужна проверка** — карточки, которые вы уже одобрили и которые пора перепроверить. В **Проверке** — новые предложения, которые ещё не сохранены.
::

Когда карточки попадают в **Нужна проверка**, задаётся в разделе **Настройки → Общие → Состояние базы знаний**:

| Настройка | Что делает | По умолчанию |
| --- | --- | --- |
| **Срок до проверки (дней)** | Через столько дней без подтверждения одобренные карточки появляются в **Нужна проверка**. | 90 |
| **Убирать из подсказок через (дней)** | Незакреплённые карточки старше этого срока больше не появляются во время текущих сессий. Закреплённые остаются. | 180 |
| **Напоминания о проверке базы знаний** | Показывает напоминания в приложении, когда одобренные карточки слишком долго не подтверждались. | Выкл. |

## Поиск карточек

- **Поиск** находит карточки по тексту.
- Период показывает карточки за **Сегодня**, **Эта неделя**, последние 7, 10, 15 или 30 дней или **Все карточки**. Сначала выбраны последние 7 дней.
- **Фильтр по категории** показывает один тип карточек.
- **Другие фильтры** сужают список по полям **Контакт**, **Компания**, **Документ** или по дате **Подтверждено** (например, **Подтверждено за 30 дней** или **Не подтверждалось**).

## Добавление карточки

Добавить карточки можно двумя способами. Оба начинаются с кнопки **Добавить карточку** — на вкладке «Карточки знаний», на вкладке **База знаний** сессии или во время подготовки к сессии. На странице проекта выберите **Добавить** → **Карточка знаний** или **Извлечь карточки**.

- **Новая карточка** (**Написать карточку**): введите **Название**, выберите **Категорию**, добавьте **Подробности** и укажите, **Где доступна** карточка. Карточки, которые вы пишете сами, считаются проверенными и сохраняются сразу.
- **Извлечь карточки**: ИИ читает сессию или документ и предлагает черновики карточек. Каждый черновик вы проверяете, прежде чем он станет карточкой. См. [Проверка и поиск знаний](/knowledge/review-and-scans).

## Изменение карточки и действия с ней

Откройте меню карточки **⋮** или откройте саму карточку и воспользуйтесь её кнопками. Показываются только действия, подходящие для статуса карточки.

| Действие | Что делает |
| --- | --- |
| **Изменить** | Меняет название, подробности, тип или уверенность. |
| **Перенести** | Переносит карточку в проект или в **Общее** либо добавляет её в серию сессий. |
| **Актуально** | Подтверждает карточку и обновляет её дату **Подтверждено**. Устаревшую карточку снова делает одобренной. |
| **Закрепить** / **Открепить** | Закрепляет карточку, чтобы она стояла выше в подсказках во время записи. |
| **Устарело** | Переносит карточку в **Устарело**. |
| **В архив** | Скрывает карточку из поиска. Она остаётся в разделе **В архиве**. |
| **Восстановить** | Возвращает карточку из архива в **Одобрено**. |
| **Отметить как дубликат…** | В открытой карточке: отмечает её как дубликат другой карточки, которую вы выберете. Эта карточка помечается как устаревшая и заменяется выбранной. |
| **Сохранить за пределами сессии** | Для карточки, которая относится только к одной сессии: делает её доступной везде. |
| **Забыть** | Безвозвратно удаляет карточку, её связи и подробности её истории. Исходный транскрипт сессии не меняется. Это действие нельзя отменить. |

**Выбрать карточки** позволяет работать сразу с несколькими карточками: **Подтвердить**, **Закрепить**, **Сменить тип**, **Перенести** или **В архив**.

## Область: общее, проект или серия

Каждая карточка где-то хранится. От этого зависит, где она видна и когда её использует ИИ.

| Область | Значение |
| --- | --- |
| **Вся база знаний** / **Общее** | Карточка относится ко всему рабочему пространству, а не к одному проекту. |
| **Проект** | Карточка хранится в одном проекте. Она видна на вкладке **Карточки знаний** этого проекта. |
| **Только эта сессия** | Карточка остаётся в одной сессии. В сессиях, записанных в режиме конфиденциальности **Только сессия** или **Конфиденциальный**, карточки всегда хранятся так. |

Карточки также можно добавить в **серию сессий**, чтобы они были видны при просмотре этой серии.

Переключатель области в правом верхнем углу базы знаний меняет содержимое всех её вкладок:

- **Вся база знаний** — всё рабочее пространство.
- **Общее** — только элементы, не привязанные к проекту.
- Проект (**Проект: название**) или серия (**Серия: название**) — только элементы этого проекта или серии.

## Привязка карточек к сессии

У сессии есть своя **база знаний** — карточки, которые должны быть под рукой во время звонка. В неё помещается до 24 карточек.

- До звонка добавьте карточки, когда [готовите запланированную сессию](/sessions/scheduling-and-preparing), или в настройках сессии.
- На вкладке **База знаний** сессии выберите **Добавить карточку** → **Новая карточка**, **Извлечь карточки** или **Добавить из базы знаний**. **Добавить из базы знаний** позволяет выбрать уже одобренные карточки.
- Во время текущей сессии нажмите **Добавить** на панели базы знаний.

Чтобы убрать карточку из базы знаний сессии, откройте её меню и выберите **Убрать из сессии**. Карточка останется в базе знаний.

## Карточки, которые подсвечиваются во время звонка

Пока идёт запись, TalkBar отслеживает в разговоре карточки из базы знаний сессии. Когда в разговоре упоминается карточка, она получает отметку **Упомянуто только что**. Это называется подсказками во время записи. Они работают на вашем компьютере и ничего не отправляют ИИ-модели.

На панели **База знаний** текущей сессии три вида. Каждый появляется, когда ему есть что показать:

| Вид | Что показывает |
| --- | --- |
| **Упоминания** | Карточки и задачи, которые прозвучали в разговоре, новые сверху. **Прозвучало** показывает, что было сказано. **Не по теме** перестаёт отмечать этот элемент в этой сессии. |
| **Карточки** | Карточки из базы знаний этой сессии. |
| **Задачи** | Задачи, взятые на эту встречу. |

В меню карточки во время записи можно выбрать **Закрепить**, **Актуально**, **В заметку**, **Копировать**, **Сделать задачей** (сохранить её как задачу), открыть карточку в базе знаний или **Убрать из сессии**.

Кнопка **Макет** в текущей сессии позволяет выбрать, где находится панель базы знаний, или показывать карточки поверх окна у правого края.

::screenshot{src="/screenshots/knowledge/live-knowledge-panel.png" alt="Текущая сессия с открытой панелью «База знаний» в виде «Карточки»; одна карточка подсвечена отметкой «Упомянуто только что»" caption="Карточка подсвечивается во время звонка"}
::

После сессии на её вкладке **База знаний** видны **База знаний** сессии и карточки из блока **Прозвучало в разговоре**.

### На что влияет режим конфиденциальности

Режим конфиденциальности сессии определяет, появляются ли карточки во время записи:

| Режим конфиденциальности | Подсказки во время записи |
| --- | --- |
| **Обычный** | Карточки подсвечиваются, когда их упоминают. |
| **Только сессия** | Карточки подсвечиваются. Добавленные карточки остаются в этой сессии. |
| **Без автокарточек** | Во время сессии карточки не всплывают. «Спросить ИИ» и поиск работают. |
| **Конфиденциальный** | Подсказки, «Спросить ИИ», предложения и поиск выключены. |
