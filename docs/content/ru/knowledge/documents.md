Приведённые ниже сочетания клавиш — значения по умолчанию для Windows. В macOS проверьте сочетание в TalkBar или его настройках; настраиваемые сочетания можно изменить там же.

**Документы** — это файлы, которые вы добавляете в TalkBar: брифы, договоры, спецификации, слайды, заметки из других приложений. TalkBar извлекает из них текст на этом компьютере и индексирует его, чтобы чаты, подготовка к сессиям и поиск знаний могли использовать документы как источники.

Откройте **База знаний → Документы**, чтобы увидеть библиотеку документов.

::screenshot{src="/screenshots/knowledge/documents-library.png" alt="База знаний → вкладка «Документы»: вкладки типов «Все», «Markdown», «PDF», «Документы», «Другое», сортировка и поиск и сетка карточек документов, на одной из которых ещё идёт «Индексация» с процентом" caption="Библиотека документов"}
::

## Поддерживаемые форматы

| Тип | Типы файлов |
| --- | --- |
| **PDF** | `.pdf` |
| **Markdown** и текст | `.md`, `.markdown`, `.txt` |
| **Документы** (Word и похожие) | `.doc`, `.docx`, `.odt`, `.rtf` |
| Таблицы | `.xls`, `.xlsx`, `.ods`, `.csv` |
| Презентации | `.ppt`, `.pptx`, `.odp` |
| Электронные книги | `.epub` |

Размер каждого файла — до **64 МБ**.

## Импорт документов

1. Откройте **База знаний → Документы** и нажмите **Добавить документы**. (На вкладке **Карточки знаний** кнопка **Импорт документов** ведёт сюда же.)
2. Выберите **Добавить файлы**, **Добавить папку** или перетащите файлы в диалог. Можно добавить сразу много файлов. **Добавить папку** импортирует поддерживаемые файлы из папки и её вложенных папок.
3. В поле **Сохранить в** выберите проект или оставьте документы в **Общем**.
4. Нажмите **Добавить документы**.

TalkBar читает каждый файл, добавляет его в библиотеку и строит для него поисковый индекс. В диалоге видно, сколько файлов импортировано и сколько не удалось. Пока идёт индексация, диалог можно закрыть.

Файлы неподдерживаемых типов пропускаются, и диалог сообщает, сколько их.

### Статус документа

| Статус | Значение |
| --- | --- |
| **В очереди…** | Ждёт индексации. |
| **Индексация… · n%** | TalkBar индексирует документ. |
| Готов | Значка нет. По документу можно искать, его можно использовать как источник. |
| **Ошибка импорта** | TalkBar не смог прочитать файл. **Повторить** пробует ещё раз. |
| **Источник изменился** | Исходный файл на диске изменился после импорта. **Обновить из файла** перечитывает его. |

## Поиск по словам и по смыслу

По документам всегда можно искать по точным словам. Чтобы находить и фрагменты с тем же смыслом, но другими словами, TalkBar использует локальную модель смыслового поиска.

Если модель не установлена, на вкладке «Документы» появляется баннер о том, что поиск работает только по ключевым словам. Нажмите **Установить модель**, чтобы один раз скачать её. Она работает на вашем компьютере.

Как искать по документам:

- Поле поиска на вкладке «Документы» фильтрует документы по названию и тексту предпросмотра.
- Общий поиск по приложению (`Ctrl+K`) находит фрагменты документов вместе с сессиями, заметками и карточками. См. [Знакомство с интерфейсом](/getting-started/getting-around).
- Откройте документ и ищите внутри него (см. ниже).

## Чтение документа

Нажмите на документ, чтобы открыть его в окне просмотра. Там показан текст, который TalkBar извлёк из файла.

- **Поиск в** документе. Переходите между совпадениями кнопками **Предыдущее совпадение** и **Следующее совпадение**. Совпадения подсвечиваются.
- Открывайте до **пяти** документов во вкладках. **Просмотр** → **Загрузить файл** или **Из библиотеки документов** добавляет вкладки, а поиск идёт сразу по всем открытым документам.
- **О файле** показывает тип, размер, источник и время добавления документа. Для документа, импортированного через **Добавить папку**, показана также **Папка импорта**. В разделе **База знаний** указано, сколько карточек получено из документа и сколько из них, возможно, устарели.
- В **Связанных** — привязанные элементы базы знаний.
- **Спросить ИИ** открывает чат о документе на боковой панели.
- **Найти знания** просит ИИ найти в документе карточки знаний, людей и компании. См. [Проверка и поиск знаний](/knowledge/review-and-scans).

## Порядок в документах

- **Вкладки типов**: **Все**, **Markdown**, **PDF**, **Документы** и **Другое** (текст, таблицы, слайды, электронные книги). **Фильтр по виду** определяет, какие вкладки типов видны, а **Сделать основным** сохраняет ваш выбор.
- **Сортировка** по дате добавления или по названию. **Закреплённые сверху** показывает закреплённые документы первыми.
- Переключатель области в правом верхнем углу базы знаний показывает документы всего рабочего пространства, **Общего** или одного проекта либо серии.

В меню каждого документа есть:

| Действие | Что делает |
| --- | --- |
| **Открыть** | Открывает окно просмотра. |
| **Закрепить** / **Открепить** | Держит документ вверху списка. |
| **Перенести** | Относит документ к проекту, к **Общему** или к серии. |
| **Найти знания** | Ищет в документе предложения. |
| **Связанные…** | Показывает привязанные элементы базы знаний. **Добавить связь** связывает документ с другим элементом. |
| **Обновить из файла** | Перечитывает исходный файл с диска. |
| **Показать в проводнике** (Windows), **Показать в Finder** (macOS) | Показывает исходный файл. Только для документов, импортированных из файла на диске. |
| **Удалить** | Удаляет документ из библиотеки и из поиска. Это действие нельзя отменить. |

**Выбрать документы** позволяет **Открыть** несколько документов во вкладках, **Перенести** их в проект, в **Общее** или в серию либо **Удалить** их.

## Документы в сессиях

К сессии можно привязать документы, чтобы ИИ учитывал их как контекст во время звонка и при ответах на вопросы о сессии.

- **Перед сессией**: добавьте документы, когда [готовите запланированную сессию](/sessions/scheduling-and-preparing).
- **Во время сессии**: добавьте панель **Документы** через **Макет** в текущей сессии.
- **После сессии**: откройте вкладку **Документы** сессии.

Нажмите **Добавить** и выберите **Загрузить файл**, **Из библиотеки документов** или **Из заметок**.

::callout{icon="i-heroicons-information-circle" color="gray"}
К сессии можно привязать до **трёх** источников — документов и заметок вместе. Чтобы добавить новый, уберите один из них.
::

**Убрать из сессии** отвязывает документ от сессии. Он остаётся в библиотеке, и по нему по-прежнему можно искать.

## Документы в чатах и проектах

- В чате нажмите **Добавить источники**, чтобы прикрепить документ, или введите **@** и выберите его. См. [Спросить TalkBar](/chats-and-notes/ask-talkbar).
- На вкладке **Документы** проекта перечислены документы, сохранённые в нём. Чтобы добавить документ, выберите на странице проекта **Добавить** → **Документ**. См. [Проекты](/knowledge/projects).
