Кнопка быстрых действий — круглая кнопка в правом нижнем углу окна TalkBar. Она открывает короткое меню с ярлыками и кнопками «назад» и «вперёд». В разделе **Настройки → Быстрые действия** можно включить или выключить эту кнопку и выбрать, какие ярлыки в ней будут.

Обзор главного окна — в разделе [Знакомство с интерфейсом](/getting-started/getting-around).

::

## Включить быстрые действия

| Настройка | Что делает | По умолчанию |
| --- | --- | --- |
| **Включить быстрые действия** | Показывает кнопку быстрых действий на каждой странице. На экране записи и на экране настройки сессии кнопка не появляется никогда. | Вкл. |

Если настройка выключена, список **Пункты меню** помечен как **Отключено**, и изменить его нельзя, пока вы снова не включите кнопку.

::callout{icon="i-heroicons-light-bulb" color="primary"}
Значок шестерёнки вверху открытого меню быстрых действий сразу ведёт на эту вкладку.
::

## Пункты меню

**Пункты меню** — список ярлыков в плавающем меню в том порядке, в котором они там показаны.

| Элемент | Что делает |
| --- | --- |
| **Добавить действие** | Открывает окно **Выберите ярлык:** с полем поиска и всеми ярлыками, которых ещё нет в меню. Нажмите на ярлык, чтобы добавить его в конец списка. Когда в меню уже есть все ярлыки, кнопка недоступна. |
| Значок перетаскивания | Перетащите строку вверх или вниз, чтобы изменить порядок. |
| Удалить (корзина) | Убирает ярлык из меню после подтверждения кнопкой **Убрать ярлык**. Позже его можно добавить снова. |

### Доступные ярлыки

| Ярлык | Что открывает | В меню по умолчанию |
| --- | --- | --- |
| **Главная** | Главную страницу. | Да |
| **Новая сессия** | Окно новой сессии. | Да |
| **Запись** | Экран записи. После завершения сессии этот пункт называется **Последняя сессия**. | Нет |
| **Сессии** | Список сессий. | Да |
| **Календарь** | Предстоящие сессии в календаре. | Нет |
| **Чаты** | Список чатов. | Нет |
| **База знаний** | Карточки знаний. | Нет |
| **Заметки** | Список заметок. | Нет |
| **Документы** | Импортированные документы. | Нет |
| **Проекты** | Список проектов. | Нет |
| **Чат** | Открывает панель чата («Спросить TalkBar») на текущей странице. | Да |
| **Настройки** | Настройки. | Да |

Меню по умолчанию: **Главная**, **Новая сессия**, **Сессии**, **Чат** и **Настройки**, именно в таком порядке.
