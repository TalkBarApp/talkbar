На вкладке **Настройки → Аккаунт** на одной странице собраны ваши профили и рабочие пространства. Её также можно открыть, нажав на своё имя и название пространства внизу главной боковой панели.

::screenshot{src="/screenshots/settings/account-page.png" alt="Вкладка «Настройки → Аккаунт»: вверху список «Профили» с одним профилем по умолчанию, ниже — список «Пространства», в котором текущее пространство отмечено как «Активно»" caption="Вкладка «Аккаунт»: профили вверху, рабочие пространства ниже"}
::

## Профили

Профиль — это имя, должность, email и цвет аватара, которые TalkBar использует для вас. Новые рабочие пространства получают профиль по умолчанию. Первый созданный профиль становится профилем по умолчанию.

| Настройка | Что делает | По умолчанию |
| --- | --- | --- |
| **Новый профиль** | Открывает редактор профиля, чтобы добавить ещё один профиль. | — |
| **Имя** | Ваше имя, которое показывается в сессиях и на страницах по ссылке. | — |
| **Должность** | Ваша роль, например «Менеджер по работе с клиентами». | — |
| **Email** | Ваш email. | — |
| **Цвет аватара** | Цвет аватара, когда нет фото. | — |
| **Загрузить фото** / **Сменить фото** / **Удалить фото** | Задаёт или убирает фото для аватара. | Без фото |

У каждого профиля в списке есть меню **Действия с профилем**:

- **Изменить профиль**: изменить имя, должность, email или аватар.
- **Сделать профилем по умолчанию**: новые рабочие пространства будут получать этот профиль. У текущего профиля по умолчанию вместо этого пункта показано **Уже по умолчанию**.
- **Удалить**: удаляет профиль. Все рабочие пространства, которые его использовали, переходят на профиль по умолчанию. Нельзя удалить профиль по умолчанию и последний оставшийся профиль.

Под каждым профилем TalkBar показывает, какие рабочие пространства его используют, или надпись **Не используется**.

## Рабочие пространства

Рабочие пространства полностью отделены друг от друга: у каждого свои сессии, заметки, люди, база знаний и папка данных. У пространства может быть и свой профиль.

| Элемент | Что делает |
| --- | --- |
| **Новое пространство** | Создаёт рабочее пространство. Введите **Название** и при желании выберите **Профиль**. Если профиль не выбран, пространство получает профиль по умолчанию. |
| **Перейти** | Делает это пространство активным. У активного пространства есть значок **Активно**. |
| Список профилей в каждой строке | Выбирает, какой профиль использует пространство. **Создать профиль…** создаёт профиль и сразу назначает его. |
| **Переименовать** (меню действий) | Меняет только название. Сессии, заметки и база знаний остаются как есть. |
| **В корзину** (меню действий) | Скрывает пространство. Его сессии, заметки и файлы остаются на диске, пока вы не удалите его навсегда. |

Нельзя отправить в корзину активное или последнее оставшееся рабочее пространство. Сначала перейдите в другое пространство.

::callout{icon="i-heroicons-exclamation-triangle" color="amber"}
Пока идёт запись сессии, нельзя переключать, создавать или изменять рабочие пространства. Сначала остановите сессию.
::

## Удалённые рабочие пространства

Когда в корзине есть хотя бы одно пространство, под списком появляется кнопка **Показать удалённые** (с числом пространств). Она открывает область **Удалённые пространства**:

- **Восстановить** возвращает пространство.
- **Удалить навсегда** стирает сессии, заметки, базу знаний и файлы пространства. Отменить это нельзя. Для подтверждения введите полное название пространства. Флажок **Создайте резервную копию** установлен по умолчанию, поэтому TalkBar сохраняет резервную копию, прежде чем что-либо стереть.

Если удаление навсегда прервётся на полпути, кнопка сменится на **Повторить**.

## Ограничения тарифа

Тариф определяет, сколько профилей и рабочих пространств может быть на этом устройстве. Когда вы достигаете предела, кнопка **Новый профиль** или **Новое пространство** становится недоступной. На странице появляется примечание, например «Рабочих пространств в вашем тарифе: 2.», со ссылкой **Подробности**. Пока вы на пределе по числу пространств, восстановить удалённое пространство тоже нельзя.

| Тариф | Профили | Рабочие пространства |
| --- | --- | --- |
| Бесплатный | 1 | 1 |
| Personal | 1 | 1 |
| Plus | 2 | 2 |
| Pro | 5 | Без ограничений |
| Business | 5 | Без ограничений |

Всё, что входит в каждый тариф, описано в разделе [Тарифы и лицензия](/data/plans-and-license).
