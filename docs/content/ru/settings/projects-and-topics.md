Две вкладки в группе настроек **Пространство** помогают упорядочить работу. **Настройки → Проекты** управляет проектами текущего рабочего пространства. **Настройки → Темы и ключевые слова** управляет вашими темами, ключевыми словами, которые ИИ находит в сессиях, и метками, с помощью которых вы фиксируете задачи.

Что такое проекты, темы и задачи и как с ними работать каждый день, описано в разделах [Проекты](/knowledge/projects), [Темы и ключевые слова](/knowledge/topics-and-keywords) и [Задачи](/knowledge/action-items).

## Проекты

На вкладке **Настройки → Проекты** перечислены все проекты рабочего пространства. Сначала идут закреплённые проекты, затем остальные в сохранённом порядке, а потом по названию. В каждой строке показаны значок проекта, его название, тип и число сессий. Проект, в котором вы сейчас работаете, отмечен как **Активно**.

::screenshot{src="/screenshots/settings/projects-tab.png" alt="Вкладка «Настройки → Проекты» со списком из нескольких проектов (один отмечен как «Активно», один закреплён), кнопкой «Новый проект» и кнопкой «Показать удалённые» внизу" caption="Настройки → Проекты"}
::

| Элемент | Что делает |
| --- | --- |
| **Новый проект** | Открывает окно **Новый проект**. Если достигнут предел проектов по вашему тарифу, TalkBar вместо этого показывает ограничения тарифа. |
| Меню строки (⋮) → **Закрепить проект** / **Открепить проект** | Закрепляет проект, чтобы он шёл первым в списке и оставался в боковой панели. |
| Меню строки (⋮) → **Изменить проект** | Открывает то же окно, чтобы изменить проект. |
| Меню строки (⋮) → **В корзину** | После подтверждения перемещает проект в корзину. Его сессии, документы и воспоминания сохраняются, а опубликованные ссылки на сессии продолжают работать. |
| **Показать удалённые (*n*)** / **Скрыть удалённые (*n*)** | Показывает или скрывает список **Удалённые проекты**. Появляется, только если в корзине есть хотя бы один проект. |

### Окно «Новый проект» и «Изменить проект»

| Поле | Что делает | По умолчанию |
| --- | --- | --- |
| Значок | Значок проекта, который показывается везде в приложении. **Использовать папку по умолчанию** сбрасывает его. | Стандартный значок папки |
| **Название** | Название проекта. | — |
| **Тип** | Вид проекта: Клиент, Контракт, Регулярный, Внутренний, Личное, Исследование, Продукт, Продажи, Найм, Обучение, Мероприятие или Поддержка. | Клиент |
| **Загрузить логотип** / **Сменить логотип** / **Удалить логотип** | Изображение, которое показывается на странице проекта. Во всех остальных местах используется значок. | Без логотипа |
| Цвет | Цвет проекта. **A** выбирает цвет автоматически. | Автоматически |
| **Организация** | Связывает проект с компанией. | Без организации |
| **Шаблон сессии по умолчанию** | Шаблон, с которым начинаются новые сессии в этом проекте. | Без шаблона по умолчанию |
| **Ссылки** | Подписанные ссылки на документы, доски или репозитории проекта. **Добавить ссылку** добавляет строку. | Нет |
| **Описание** | О чём проект. Можно вставлять Markdown и изображения. | Пусто |

### Удалённые проекты

Когда вы нажимаете **Показать удалённые**, в списке **Удалённые проекты** появляется каждый проект из корзины с датой его перемещения туда.

- **Восстановить** возвращает проект.
- **Удалить навсегда** открывает окно подтверждения. Отменить удаление нельзя.

В окне **Удалить навсегда**:

| Элемент | Что делает | По умолчанию |
| --- | --- | --- |
| **Удалить всё** / **Оставить содержимое** | **Удалить всё** стирает сессии, документы, воспоминания и извлечённые элементы проекта и отключает их опубликованные ссылки. **Оставить содержимое** удаляет только сам проект; его содержимое переходит в **Без проекта**, а опубликованные ссылки продолжают работать. | Удалить всё |
| **Создайте резервную копию** | Создаёт резервную копию перед удалением. | Вкл. |
| **Для подтверждения введите полное название проекта …** | Кнопка удаления станет доступна, только когда вы введёте точное название проекта. | — |

Если удаление навсегда прервётся на полпути, кнопка сменится на **Повторить**. Повторная попытка всегда продолжает удаление с тем вариантом, который вы выбрали в первый раз.

::callout{icon="i-heroicons-exclamation-triangle" color="amber"}
Удалить проект навсегда можно только здесь, в списке **Удалённые проекты**. Во всех остальных местах приложения удаление проекта перемещает его в корзину.
::

## Темы и ключевые слова

У вкладки **Настройки → Темы и ключевые слова** три внутренние вкладки: **Темы**, **Ключевые слова** и **Задачи**. На вкладках «Темы» и «Ключевые слова» показано число элементов.

### Темы

Темы — ваши собственные метки для сессий и заметок. Они действуют во всём рабочем пространстве, и у них есть только название и цвет.

| Элемент | Что делает |
| --- | --- |
| **Новая тема** | Открывает форму с выбором цвета и полем **Название темы** (до 80 символов). **Создать** сохраняет тему. Новая тема получает случайный цвет, если вы не выберете свой. |
| Название темы | Нажмите на название темы, чтобы открыть её страницу с сессиями и заметками, отмеченными этой темой. |
| Изменить (карандаш) | Переименуйте тему или смените её цвет, затем нажмите **Сохранить**. |
| Удалить (корзина) | Удаляет тему после подтверждения кнопкой **Удалить тему**. В окне видно, сколько сессий и заметок её используют. Эти сессии и заметки сохраняются, с них снимается только тема. |

### Ключевые слова

Ключевые слова для каждой сессии подбирает ИИ, когда готовит её итоги. Здесь они появляются после первых итогов.

::screenshot{src="/screenshots/settings/topics-keywords-tab.png" alt="Вкладка «Настройки → Темы и ключевые слова» с открытой внутренней вкладкой «Ключевые слова»: выбрано несколько ключевых слов, на панели выбора кнопки «Превратить в темы», «Показать сессии», «Очистить» и «Удалить»" caption="Вкладка «Ключевые слова» с выбранными словами"}
::

| Элемент | Что делает | По умолчанию |
| --- | --- | --- |
| **Поиск ключевых слов** | Фильтрует список по тексту. | Пусто |
| **Все** / **Без темы** | **Без темы** показывает только ключевые слова, которые пока не совпадают ни с одной из ваших тем. | Все |
| Нажатие на ключевое слово, **Выбрать все** | Выбирает ключевые слова для массового действия. Чтобы снять выбор, нажмите на выбранное слово ещё раз. | — |
| Удалить (×) на ключевом слове | После подтверждения удаляет одно это ключевое слово. | — |
| **Превратить в темы** | Создаёт тему для каждого выбранного ключевого слова (или использует существующую тему с тем же названием) и назначает её сессиям с этим ключевым словом. Ключевые слова остаются у сессий. | — |
| **Показать сессии** | Открывает список сессий, отфильтрованный по выбранным ключевым словам. | — |
| **Очистить** | Снимает выбор. | — |
| **Удалить** | Удаляет выбранные ключевые слова из всех сессий, где они есть. ИИ не добавит их снова, если вы сами не добавите их в сессию. | — |
| Меню ключевого слова → **Превратить в тему** | Превращает в тему одно ключевое слово. Если тема с таким названием уже есть, вам предложат **Назначить тему**; иначе вы называете новую тему и выбираете **Создать и назначить**. | — |
| **Показать ещё** | Загружает следующую часть ключевых слов, если список длинный. | — |

### Задачи

Внутренняя вкладка **Задачи** управляет разделом **Метки задач**: названиями, значками, цветами и порядком вариантов, которые вы видите, когда фиксируете задачу.

::screenshot{src="/screenshots/settings/action-item-labels.png" alt="Внутренняя вкладка «Настройки → Темы и ключевые слова → Задачи»: в списке «Каталог» выбрано «Общие для пространства», четыре встроенные метки («Задача», «Напоминание», «Вопрос», «Решение») и ниже список «Отключённые метки»" caption="Метки задач"}
::

| Элемент | Что делает | По умолчанию |
| --- | --- | --- |
| **Каталог** | Выбирает, какие метки вы редактируете: **Общие для пространства** (доступны во всех проектах и в сессиях без проекта) или метки одного проекта. Метки проекта добавляются к меткам пространства, и у них может быть свой порядок. | Общие для пространства |
| **Добавить метку** | Создаёт метку в выбранном каталоге. | — |
| Значок перетаскивания | Перетащите строку, чтобы изменить порядок меток в меню добавления. | — |
| Меню метки → **Изменить** | Измените значок, название или цвет метки. | — |
| Меню метки → **Скрыть из меню добавления** / **Показать в меню добавления** | Скрывает метку, не удаляя её. Скрытые метки переходят в список **Отключённые метки**. | — |
| Меню метки → **В архив** | Убирает созданную вами метку из меню добавления. У существующих задач сохраняются её название, значок и цвет. Встроенные метки отправить в архив нельзя. | — |
| **Включить** (в списке **Отключённые метки**) | Включает готовую или скрытую метку. | — |

В каталоге проекта метки с пометкой **Задаётся для всего пространства** берутся из рабочего пространства. Для проекта их можно переставить, но изменяются они в каталоге **Общие для пространства**.

**Встроенные метки.** В каждом рабочем пространстве изначально видны четыре метки: **Задача**, **Напоминание**, **Вопрос** и **Решение**. Кроме того, есть готовые метки, которые находятся в списке **Отключённые метки**, пока вы их не включите: Идея, Риск, Препятствие, Обязательство, Запрос, Ожидание, Делегировано, На потом, Исследование, Договорённость и Компромисс.

**Поведение.** Добавляя метку, вы выбираете её **Поведение**. После создания метки его нельзя изменить.

| Поведение | Статусы | Сроки и исполнители |
| --- | --- | --- |
| **Задача** | Открыто → Готово | Да |
| **Напоминание** | Открыто → Готово | Да |
| **Вопрос** | Открыто → Есть ответ, с полем для ответа | Без сроков |
| **Решение** | Активно → Заменено | Без сроков |

В итогах ИИ фиксирует задачи как задачи, вопросы — как открытые вопросы, а решения — как решения.
