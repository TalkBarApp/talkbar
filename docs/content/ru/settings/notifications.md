В разделе **Настройки → Уведомления** настраивается, куда TalkBar отправляет уведомления и материалы, которыми вы делитесь. На странице два раздела: **Каналы доставки** и **Системные уведомления**. Что и когда отправляется — в разделе [Уведомления](/sharing/notifications).

## Каналы доставки

Канал доставки — это адресат за пределами TalkBar: почтовый аккаунт, бот Telegram, канал Slack или Microsoft Teams либо ваш собственный вебхук. Каналы используются для уведомлений, которые вы выбрали для каждого канала, и для [общего доступа](/sharing/share-links). Каналов можно создать сколько угодно и включать или выключать каждый по отдельности.

Добавить канал можно двумя способами:

- **Добавить канал** вверху страницы открывает пошаговую настройку: она объясняет, где взять каждый параметр доступа, и позволяет отправить тестовое сообщение до завершения.
- **Создать канал** в разделе «Каналы доставки» открывает те же поля одной формой.

Пароли, токены ботов, URL вебхуков и значения заголовков хранятся на этом компьютере в зашифрованном виде.

### Типы каналов

| Тип канала | Что понадобится |
| --- | --- |
| **Email** | Почтовый аккаунт, который может отправлять письма через SMTP. Выберите **Gmail**, **Outlook**, **Yahoo** или **Свой SMTP**. Для Gmail, Outlook и Yahoo нужен пароль приложения; в настройке есть ссылка на страницу, где его создать. |
| **Telegram** | Токен бота от @BotFather. Настройка может проверить токен и найти чаты, в которые бот может писать. |
| **Slack** | URL входящего вебхука из Slack. |
| **Microsoft Teams** | URL вебхука из триггера вебхука в Teams Workflows. |
| **Свой вебхук** | Любой HTTPS-адрес с необязательными заголовками авторизации. |

### Поля канала

Набор полей зависит от типа канала.

| Настройка | Что делает | По умолчанию |
| --- | --- | --- |
| **Тип канала** | Вид канала. Показывается только при создании канала. | **Email** |
| **Название канала** | Название в списках каналов и в окнах отправки. Обязательно. | — |
| **Провайдер** | Только для email: **Gmail**, **Outlook**, **Yahoo** или **Свой SMTP**. При выборе провайдера параметры сервера заполняются автоматически. | **Gmail** |
| **SMTP-хост** | Только для email. Сервер исходящей почты. | `smtp.gmail.com` (по выбранному провайдеру) |
| **SMTP-порт** | Только для email. | 587 |
| **Безопасность** | Только для email: **STARTTLS**, **TLS** или **Нет**. | **STARTTLS** |
| **Имя пользователя SMTP** | Только для email. Обычно это ваш email. | — |
| **SMTP-пароль** | Только для email. Пароль приложения или пароль SMTP. | — |
| **Имя отправителя** | Только для email. Имя отправителя, которое видят получатели. | — |
| **Email отправителя** | Только для email. Адрес отправителя. | — |
| **Получатели по умолчанию (необязательно)** | Только для email. Куда по умолчанию уходят уведомления и тестовые сообщения. Разделяйте адреса запятой или новой строкой. Если ваша организация разрешает отправку только на определённые домены, адреса за их пределами не принимаются. | — |
| **Токен бота** | Только для Telegram. Обязательно. | — |
| **Имя бота (необязательно)** | Только для Telegram. | — |
| **ID чатов доставки по умолчанию (необязательно)** | Только для Telegram. Чаты, в которые бот по умолчанию отправляет уведомления TalkBar. | — |
| **URL вебхука** | Slack, Microsoft Teams и «Свой вебхук». Обязательно. Только HTTPS. | — |
| Заголовки авторизации | Только для своего вебхука. Нажмите **Добавить заголовок авторизации**, чтобы указать **Имя заголовка** и **Значение заголовка** (до 16). | Нет |
| **Автоматические уведомления** | Какие уведомления получает канал: **Сессия завершена**, **Итоги готовы**, **Системные оповещения** и **События приложения**. Чтобы отправлять итоги целиком, используйте правила автоматической отправки. | Ничего не выбрано |
| **Включить** | Показывается при изменении канала. Отключённый канал ничего не отправляет. | Вкл. |

::callout{icon="i-heroicons-light-bulb" color="primary"}
**Итоги готовы** — это короткое уведомление, а не текст итогов. Чтобы отправлять итоги в канал, добавьте правило автоматической отправки в разделе [Настройки → Экспорт и отправка](/settings/export-and-share#автоматическая-отправка).
::

### Управление каналами

У каждого канала в списке показан его тип и есть:

- переключатель, который включает или отключает канал;
- **Отправить тест** — отправляет тестовое сообщение. Можно указать адресата только для этого теста или оставить поле пустым, чтобы использовать параметры канала по умолчанию;
- **Изменить** — здесь можно поменять поля и нажать **Заменить данные доступа**;
- **Удалить** — удаляет канал безвозвратно.

Если последняя доставка через канал не удалась, у него показана **Ошибка доставки** с причиной. Если TalkBar не может прочитать сохранённый пароль или токен на этом компьютере, канал попросит ввести его снова.

## Системные уведомления

| Настройка | Что делает | По умолчанию |
| --- | --- | --- |
| **Системные уведомления** | Переключатель в заголовке раздела. Пока он включён, TalkBar показывает напоминания и события в системных уведомлениях. | Вкл. |
| **Системные настройки** | Открывает настройки уведомлений операционной системы, где можно разрешить уведомления TalkBar или отключить их звук. | — |
| **Отправить тест** | Показывает тестовое системное уведомление. Доступно, пока системные уведомления включены. | — |

::callout{icon="i-heroicons-exclamation-triangle" color="amber"}
Если TalkBar управляет ваша организация, некоторые типы каналов или весь раздел «Каналы доставки» могут быть заблокированы. В уведомлении на странице сказано, какое правило действует.
::
