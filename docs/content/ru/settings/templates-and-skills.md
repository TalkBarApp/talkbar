На вкладке **Настройки → Шаблоны и навыки** хранятся готовые блоки, которые TalkBar использует вместе с ИИ. У вкладки пять внутренних вкладок: **Шаблоны сессий**, **Разделы итогов**, **Шаблоны заметок**, **Навыки** и **База знаний**. На этой странице описано, что показывает каждая вкладка и какие действия на ней доступны. Что шаблоны и навыки делают в сессии, рассказано в разделе [Шаблоны и навыки](/sessions/templates-and-skills).

::callout{icon="i-heroicons-lock-closed" color="amber"}
Создавать, изменять, дублировать и импортировать шаблоны сессий, разделы итогов и шаблоны заметок можно на тарифах Plus, Pro и Business. Создавать, изменять, дублировать и импортировать навыки и навыки для базы знаний можно на тарифах Pro и Business. На любом тарифе элементы можно просматривать, включать и выключать, закреплять, выбирать по умолчанию, экспортировать, восстанавливать встроенные и удалять свои. На тарифе без этих действий вместо кнопок показывается пометка **Свои шаблоны** или **Свои навыки** с нужным тарифом, а **Изменить** и **Дублировать** исчезают из меню. См. [Тарифы и лицензия](/data/plans-and-license).
::

## Общие элементы управления

**Шаблоны сессий**, **Шаблоны заметок**, **Навыки** и **База знаний** устроены одинаково:

- Число рядом с названием вкладки показывает, сколько элементов включено.
- Поле поиска и фильтр по категории (или группе) сужают список. В фильтре можно выбрать сразу несколько значений.
- На каждой карточке есть переключатель, который включает или выключает элемент. Выключенные элементы отмечены значком **Отключено** и остаются в списке, чтобы их можно было снова включить.
- На каждой карточке есть кнопка закрепления. На вкладке **База знаний** это закладка, которая отмечает навык по умолчанию.
- Нажмите на карточку, чтобы открыть её только для чтения. Чтобы увидеть действия, нажмите кнопку **⋮** или щёлкните карточку правой кнопкой мыши.
- Встроенные элементы, которые вы изменили, отмечены значком **Изменён**. Наведите на него указатель, чтобы увидеть когда. Элементы, которые вы создали или импортировали, отмечены значком **Свой**.
- **Экспорт** сохраняет элемент как файл Markdown в выбранное вами место.
- **Восстановить исходный** возвращает изменённому встроенному элементу исходное содержимое после подтверждения. Этот пункт есть только у встроенных элементов, которые вы меняли. Состояние «включён или выключен» и закрепление сохраняются.
- **Удалить** доступно только для элементов, которые вы создали или импортировали, и требует подтверждения. Встроенные элементы можно выключить, но не удалить.

### Импорт

| Вкладка | Какие файлы читает | Что происходит |
| --- | --- | --- |
| **Шаблоны сессий** | `.md`, `.markdown`, `.yml` или `.yaml`, экспортированные из TalkBar | Сразу добавляет один шаблон в категорию **Свои**. Если такое название уже есть, TalkBar добавит к нему *(imported)*. |
| **Шаблоны заметок** | `.md`, `.markdown`, `.yml` или `.yaml`, экспортированные из TalkBar, до 1 МБ | Сразу добавляет один шаблон в категорию, указанную в файле. Если такое название уже есть, TalkBar добавит к нему номер. |
| **Навыки** | `.md`, `.markdown` или `.txt`, до 64 КБ | Открывает редактор, чтобы вы могли проверить навык. **Импорт навыка** добавляет его. См. [Управление навыками и создание своих](/sessions/templates-and-skills#управление-навыками-и-создание-своих). |
| **База знаний** | `.md`, `.markdown` или `.txt`, до 64 КБ | Открывает редактор **Импорт навыка для базы знаний**. Файл без категории базы знаний попадает в **Главное**. **Импорт навыка** добавляет его. |

Импорт файла, сделанного из встроенного элемента, добавляет вашу собственную копию. Сам встроенный элемент не меняется.

## Шаблоны сессий

Шаблон сессии описывает тип сессии: разделы итогов, которые пишет ИИ, его инструкции и то, как фиксируются участники. Включённые шаблоны предлагаются, когда вы начинаете сессию.

::screenshot{src="/screenshots/settings/templates-session-templates.png" alt="Вкладка «Настройки → Шаблоны и навыки» с открытой внутренней вкладкой «Шаблоны сессий»: кнопки «Новый шаблон» и «Импорт», поле поиска и фильтр по категории, группа «Закреплено» и карточки шаблонов с переключателями" caption="Шаблоны сессий"}
::

В TalkBar 28 встроенных шаблонов сессий, 15 из них включены, например **Встреча**, **1:1**, **Звонок**, **Интервью** и **Голосовая заметка**. Шаблоны сгруппированы по категориям: **Встречи**, **Звонки и 1:1**, **Клиенты и сделки**, **Интервью**, **Прослушивание**, **Соло**, затем ваши категории по алфавиту и в конце **Свои** — для шаблонов, которые вы создали, скопировали или импортировали. См. [полный список](/sessions/templates-and-skills#что-входит-во-встроенные-шаблоны).

| Элемент | Что делает |
| --- | --- |
| **Новый шаблон** | Открывает редактор для нового шаблона. |
| **Импорт** | Добавляет шаблон из файла. См. [Импорт](#импорт). |
| **Поиск шаблонов сессий…** | Ищет по названиям, описаниям и заголовкам разделов. |
| **Фильтр по категории** | Показывает только выбранные категории. |
| Группа **Закреплено** | Закреплённые шаблоны предлагаются первыми, когда вы начинаете или планируете сессию. Порядок можно менять перетаскиванием. В новых рабочих пространствах закреплены **Звонок**, **Встреча**, **1:1** и **Подкаст**. Во время поиска или фильтрации перетаскивание отключено. |
| Низ карточки | Число разделов и переключатель. |

Действия в меню карточки шаблона:

| Действие | Что делает |
| --- | --- |
| **Изменить** | Открывает [редактор шаблона](#редактор-шаблона). |
| **Закрепить** / **Открепить** | Добавляет шаблон в группу **Закреплено** или убирает его оттуда. |
| **Дублировать** | Создаёт в категории **Свои** копию, которую можно изменять. |
| **Сделать основным** | Делает шаблон шаблоном по умолчанию. Текущий шаблон по умолчанию отмечен значком **Основной**. Пока вы его не поменяете, шаблон по умолчанию — «Встреча». Недоступно для выключенных шаблонов. Последний использованный и закреплённые шаблоны выбираются раньше него: см. [С какого шаблона начинается сессия](/sessions/templates-and-skills#с-какого-шаблона-начинается-сессия). |
| **Экспорт…** | Сохраняет шаблон как файл Markdown. |
| **Восстановить исходный** | Заменяет ваши изменения исходным встроенным шаблоном. Уже существующие сессии сохраняют версию, с которой они были созданы. |
| **Удалить** | Удаляет созданный вами шаблон. Завершённые сессии сохраняют свои итоги, а серии, которые его использовали, лишаются этого шаблона. |
| **Создать шаблон заметки из заголовков** | Начинает новый шаблон заметки в категории **Общие** с названием, значком и заголовками разделов этого шаблона. Он сохраняется только после нажатия **Сохранить шаблон**. |

### Обзор шаблона

Нажатие на карточку открывает обзор только для чтения: название, описание и значки, **Контекст сессии**, **Разделы** с инструкциями и форматами, **Свои инструкции для ИИ**, если они заданы, и **Подробности** (**Запись**, **Заметки по ходу** и число терминов в поле **Словарь**). Кнопки: **Изменить**, **Восстановить исходный** у изменённого встроенного шаблона и **Закрыть**.

### Редактор шаблона

| Поле | Что делает | Ограничение или значение по умолчанию |
| --- | --- | --- |
| **Название** | Название шаблона. Обязательно. | До 80 символов |
| **Значок** | Значок на карточках и в окне «Новая сессия». | |
| **Категория** | Группа, в которой показывается шаблон. **Новая категория…** позволяет ввести своё название; название, совпадающее с существующей категорией, присоединяется к ней. | Сначала **Свои**. Новые названия до 40 символов |
| **Описание** | Одна строка о том, когда использовать шаблон. | До 300 символов |
| **Контекст сессии** | Что это за сессии, кто в них участвует и что важно. | До 2 000 символов |
| **Разделы** | Разделы итогов по порядку. Заголовок и инструкции меняются прямо в строке. Порядок меняется перетаскиванием. **Добавить раздел** добавляет строку. У повторяющихся заголовков показывается **Заголовок повторяется**. | До 10. У каждого должны быть заголовок и инструкции |
| **Параметры раздела** | Показывает **Ключ вывода** (постоянное имя, под которым TalkBar хранит раздел) и позволяет выбрать формат, **Включить раздел** / **Отключить раздел** или **Удалить раздел**. | Новые разделы получают формат **Пункты** |
| **Запись** (**Дополнительно**) | **Микрофон**, **Системный звук** или **Микрофон + системный звук**. | **Микрофон + системный звук** |
| **Минимум участников**, **Обычное число участников**, **Максимум участников** | Ожидаемое число участников и диапазон, в котором оно остаётся. **Обычное число участников** определяет, что предложит окно «Новая сессия»: 2 — **Вы + 1**, 5 и больше — **Много (5–8)**, всё остальное — **Несколько (2–4)**. | От 1 до 16. По умолчанию 1, 2 и 6 |
| **Разделять голоса** | Включено: **Голоса разделяются автоматически.** Выключено: **Всё распознаётся как речь одного участника.**, и окно предлагает **Только вы**. | Включено |
| **Заметки по ходу** | **Личные заметки — записывайте свои мысли**, **Контент — следите за тем, что показывают** или **Разговор — кто что сказал**. | **Разговор** |
| Инструкции для заметок | **Указания для заметок по ходу записи.** | До 2 000 символов |
| **Фокус для базы знаний** | На что обращать внимание, сохраняя знания. | До 2 000 символов |
| **Словарь** | Имена, продукты и жаргон для заметок и итогов ИИ. Введите **Термин** и при желании **Подсказка (необязательно)**, затем нажмите **Добавить** или `Enter`. Термин, который уже есть в списке, не добавляется. | До 100 терминов |
| **Свои инструкции для ИИ** | Дополнительные указания для итогов: тон, оформление, что всегда включать или чего избегать. | До 1 000 символов |

Внизу редактора: **Сохранить шаблон**, **Дублировать** (сохраняет копию и открывает её), **Восстановить исходный** у изменённого встроенного шаблона и **Отмена**.

## Разделы итогов

На этой вкладке перечислены все разделы итогов, сгруппированные по шаблонам сессий, к которым они относятся, чтобы разделы можно было настраивать, не открывая каждый шаблон. Выключенные шаблоны здесь тоже есть. В каждой группе также показаны **Контекст сессии** шаблона и, если они заданы, его **Свои инструкции для ИИ**. Число рядом с названием вкладки — это количество включённых разделов. В отличие от редактора шаблона, здесь каждое изменение сохраняется сразу.

| Элемент | Что делает |
| --- | --- |
| **Поиск разделов** | Ищет разделы по заголовку, инструкциям или названию шаблона. |
| **Фильтр по категории** | Показывает только шаблоны из выбранных категорий. |
| Значок перетаскивания | Меняет порядок разделов в шаблоне. Итоги пишутся в этом порядке. Во время поиска перетаскивание отключено. |
| **Изменить** (меню блока **Контекст сессии**) | Изменяет контекст сессии прямо на месте. **Сохранить** или **Отмена**. До 2 000 символов. |
| **Изменить** (меню блока **Свои инструкции для ИИ**) | Изменяет инструкции прямо на месте. До 1 000 символов. Если сохранить их пустыми, они будут удалены. |

Меню **Параметры шаблона** у каждой группы:

| Действие | Что делает |
| --- | --- |
| **Добавить раздел** | Добавляет строку с заголовком, инструкциями и форматом из меню **Параметры нового раздела**. **Сохранить** или **Отмена**. При 10 разделах пункт выглядит как **Добавить раздел — максимум 10**. |
| **Добавить свои инструкции для ИИ** | Добавляет дополнительные инструкции для итогов целиком. Показывается, если у шаблона их нет. |
| **Восстановить исходный** | Восстанавливает весь встроенный шаблон после подтверждения. Показывается, если шаблон изменён. |

Меню **Параметры раздела** у каждого раздела:

| Действие | Что делает |
| --- | --- |
| **Ключ вывода** | Только для чтения. Постоянное имя, под которым TalkBar хранит раздел. |
| **Изменить** | Изменяет заголовок и инструкции прямо на месте. **Сохранить** или **Отмена**. |
| **Пункты**, **Пункты с ответственными**, **С отметками времени**, **Абзац**, **Вопросы и ответы** | Задаёт [формат пунктов](/sessions/templates-and-skills#разделы-итогов). У текущего стоит галочка. |
| **Включить раздел** / **Отключить раздел** | Отключённый раздел остаётся в шаблоне, но не попадает в итоги. |
| **Восстановить раздел** | Возвращает изменённому встроенному разделу исходную формулировку после подтверждения. Показывается только у изменённых разделов. |
| **Удалить раздел** | Удаляет раздел после подтверждения. В новых итогах его не будет. У завершённых сессий останутся их итоги. |

Заголовок раздела ограничен 80 символами, а инструкции раздела — 500. На тарифе без изменения шаблонов при попытке что-то поменять здесь откроются ограничения тарифа.

## Шаблоны заметок

Шаблоны заметок дают новой заметке готовую структуру из заголовков и подсказок по содержанию. В TalkBar 44 встроенных шаблона заметок, сгруппированных по категориям: **Общие**, **Продажи**, **Успех клиентов**, **Продукт**, **Разработка**, **Найм**, **Руководство**, **Команда** и **Личное и обучение**. Как ими пользоваться, описано в разделе [Заметки](/chats-and-notes/notes).

| Элемент | Что делает |
| --- | --- |
| **Новый шаблон** | Открывает [редактор шаблона заметки](#редактор-шаблона-заметки). |
| **Импорт** | Добавляет шаблон заметки из файла. См. [Импорт](#импорт). |
| **Поиск шаблонов заметок…** / **Фильтр по категории** | Сужают список. Поиск также охватывает категории и заголовки разделов. |
| Группа **Закреплено** | Закреплённые шаблоны предлагаются первыми, когда вы пишете заметку. |
| **Изменить**, **Дублировать**, **Закрепить** / **Открепить**, **Экспорт**, **Восстановить исходный**, **Удалить** (меню карточки) | Стандартные действия, описанные в разделе [Общие элементы управления](#общие-элементы-управления). **Дублировать** открывает копию в редакторе. Удаление шаблона заметки или восстановление встроенного не меняет уже созданные заметки. |

Выключенный шаблон заметки не показывается при выборе шаблона для новой заметки, но остаётся доступен здесь.

Нажатие на карточку открывает предпросмотр структуры только для чтения с кнопками **Изменить**, **Восстановить исходный** у изменённого встроенного шаблона и **Закрыть**.

### Редактор шаблона заметки

| Поле | Что делает | Ограничение или значение по умолчанию |
| --- | --- | --- |
| **Название** | Название шаблона. Обязательно. | До 80 символов |
| **Значок** | Значок на карточках и при выборе шаблона. | |
| **Категория** | Одна из девяти категорий. Своё название задать нельзя. | **Общие** |
| **Описание** | Одна строка о том, когда использовать шаблон. | До 300 символов |
| **Заголовок раздела** | Заголовок в заметке. Обязателен для каждого раздела. | До 80 символов. От 1 до 12 разделов |
| **Подсказка** | Серая подсказка, пока раздел пуст. Она не становится текстом заметки. | До 300 символов |
| **Добавить содержимое** | Текст, который становится частью каждой заметки. Выберите **Тип начального содержимого**. В списках каждый пункт пишется с новой строки. | До 24 блоков в разделе, 50 пунктов в списке, 4 000 символов в абзаце или пункте, всего 50 000 |
| **Действия с разделом** | Задаёт формат раздела (**Абзац**, **Пункты**, **Нумерованный список** или **Чек-лист**), **Вверх**, **Вниз** и **Удалить раздел**. Разделы можно и перетаскивать. Последний раздел удалить нельзя. | **Абзац** |

Внизу редактора: **Сохранить шаблон**, **Дублировать** (создаёт копию и продолжает работу в ней), **Восстановить исходный** у изменённого встроенного шаблона и **Отмена**.

## Навыки

Навыки — это готовые ИИ-промпты, которые вы выбираете в чате, например **Составить повестку** или черновик письма после встречи. В TalkBar 24 встроенных навыка, сгруппированных так: **Перед сессией**, **Во время сессии**, **После сессии**, **По нескольким сессиям** и **Текст и редактура**. См. [полный список](/sessions/templates-and-skills#навыки).

::screenshot{src="/screenshots/settings/templates-skills.png" alt="Вкладка «Настройки → Шаблоны и навыки» с открытой внутренней вкладкой «Навыки»: кнопки «Новый навык» и «Импорт», поле поиска и фильтр по группе, группа «Закреплено» и карточки навыков" caption="Навыки"}
::

| Элемент | Что делает |
| --- | --- |
| **Новый навык** | Открывает [редактор навыка](#редактор-навыка). |
| **Импорт** | Добавляет навык из файла. См. [Импорт](#импорт). |
| **Поиск навыков…** / **Фильтр навыков по группе** | Сужают список. Поиск также охватывает инструкции. |
| Группа **Закреплено** | Ваши основные навыки, которые всегда наверху — здесь и при выборе навыка в чате. |
| **Изменить**, **Дублировать**, **Закрепить** / **Открепить**, **Экспорт**, **Восстановить исходный**, **Удалить** (меню карточки) | Стандартные действия, описанные в разделе [Общие элементы управления](#общие-элементы-управления). Копия при дублировании сразу открывается в редакторе. Если изменить, восстановить или удалить навык, прошлые чаты не изменятся. |

Нажатие на карточку открывает навык и его **Инструкции** только для чтения с такими кнопками: **Открыть в чате** (открывает новый чат с этим навыком; недоступно, пока навык выключен), **Изменить**, **Дублировать**, **Экспорт**, **Восстановить исходный** у изменённого встроенного навыка и **Закрыть**.

### Редактор навыка

| Поле | Что делает | Ограничение или значение по умолчанию |
| --- | --- | --- |
| **Название** | Название навыка. Обязательно. | До 80 символов |
| **Значок** | Значок здесь и в чате. | |
| **Группа** | Группа, в которой показывается навык. | **Текст и редактура** |
| **Описание** | Одна строка о том, чем помогает навык. | До 300 символов |
| **Инструкции для ИИ / промпт** | Задача, на что обратить внимание и какой результат нужен. Обязательно. | До 4 000 символов, счётчик виден при вводе |

Внизу редактора: **Сохранить навык** (при импорте **Импорт навыка**), **Дублировать**, **Восстановить исходный** у изменённого встроенного навыка и **Отмена**.

## База знаний

Навыки для базы знаний подсказывают ИИ, что искать, когда он просматривает документ или сессию и готовит черновики карточек знаний. В TalkBar 14 встроенных навыков для базы знаний, сгруппированных так: **Главное**, **Команда**, **Клиенты и сделки**, **Проекты и сроки** и **Подготовка к встрече**. См. [полный список](/sessions/templates-and-skills#навыки-для-базы-знаний). Как их используют при поиске знаний, описано в разделе [Проверка и поиск знаний](/knowledge/review-and-scans).

| Элемент | Что делает |
| --- | --- |
| **Новый навык для базы знаний** | Открывает редактор. Поля те же, что в [редакторе навыка](#редактор-навыка), только вместо **Группа** указывается **Категория** (сначала **Главное**). |
| **Импорт** | Добавляет навык для базы знаний из файла. См. [Импорт](#импорт). |
| **Поиск навыков для базы знаний…** / **Фильтр по категории** | Сужают список. Поиск также охватывает инструкции. |
| Группа **По умолчанию** | До 3 навыков, которые заранее выбраны при каждом поиске знаний. В заголовке показано, сколько их выбрано, например **По умолчанию (3 из 3)**. Используйте пункты **По умолчанию** или **Убрать из выбранных** в меню карточки либо закладку на карточке. Когда выбрано 3, TalkBar попросит сначала убрать один. |
| **Изменить**, **Дублировать**, **Экспорт**, **Восстановить исходный**, **Удалить** (меню карточки) | Стандартные действия, описанные в разделе [Общие элементы управления](#общие-элементы-управления). Копия при дублировании сразу открывается в редакторе. |

В новых рабочих пространствах по умолчанию выбраны три навыка: **Факты и цифры**, **Решения и обязательства** и **Риски и вопросы**.
