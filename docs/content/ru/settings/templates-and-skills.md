На вкладке **Настройки → Шаблоны и навыки** хранятся готовые блоки, которые TalkBar использует вместе с ИИ. У вкладки пять внутренних вкладок: **Шаблоны сессий**, **Разделы итогов**, **Шаблоны заметок**, **Навыки** и **База знаний**. На этой странице описано, что показывает каждая вкладка и какие действия на ней доступны. Что шаблоны и навыки делают в сессии, рассказано в разделе [Шаблоны и навыки](/sessions/templates-and-skills).

::callout{icon="i-heroicons-lock-closed" color="amber"}
Создавать, изменять, дублировать и импортировать шаблоны сессий, разделы итогов и шаблоны заметок можно на тарифах Plus, Pro и Business. Создавать, изменять, дублировать и импортировать навыки и навыки для базы знаний можно на тарифах Pro и Business. На любом тарифе элементы можно просматривать, включать и выключать, закреплять, выбирать по умолчанию, экспортировать, восстанавливать встроенные и удалять свои. См. [Тарифы и лицензия](/data/plans-and-license).
::

## Общие элементы управления

Все вкладки устроены одинаково:

- Число рядом с названием вкладки показывает, сколько элементов включено.
- Поле поиска и фильтр по категории (или группе) сужают список.
- На каждой карточке есть переключатель, который включает или выключает элемент. Выключенные элементы отмечены значком **Отключено** и остаются в списке, чтобы их можно было снова включить.
- Нажмите на карточку, чтобы открыть её только для чтения. Чтобы увидеть действия, нажмите кнопку **⋮** или щёлкните карточку правой кнопкой мыши.
- Встроенные элементы, которые вы изменили, отмечены значком **Изменён**. Элементы, которые вы создали или импортировали, отмечены значком **Свой**.
- **Импорт** читает файл Markdown (`.md`, `.markdown`) или YAML (`.yml`, `.yaml`). **Экспорт** сохраняет элемент как файл Markdown.
- **Восстановить исходный** возвращает изменённому встроенному элементу исходное содержимое. Этот пункт есть только у встроенных элементов, которые вы меняли.
- **Удалить** доступно только для элементов, которые вы создали или импортировали. Встроенные элементы можно выключить, но не удалить.

## Шаблоны сессий

Шаблон сессии описывает тип сессии: разделы итогов, которые пишет ИИ, его инструкции и то, как фиксируются участники. Включённые шаблоны предлагаются, когда вы начинаете сессию.

::screenshot{src="/screenshots/settings/templates-session-templates.png" alt="Вкладка «Настройки → Шаблоны и навыки» с открытой внутренней вкладкой «Шаблоны сессий»: кнопки «Новый шаблон» и «Импорт», поле поиска и фильтр по категории, группа «Закреплено» и карточки шаблонов с переключателями" caption="Шаблоны сессий"}
::

В TalkBar 28 встроенных шаблонов сессий, 15 из них включены, например **Встреча**, **1:1**, **Звонок**, **Интервью** и **Голосовая заметка**. Шаблоны сгруппированы по категориям: **Встречи**, **Звонки и 1:1**, **Клиенты и сделки**, **Интервью**, **Прослушивание**, **Соло**, а также своя группа для шаблонов, которые вы создали, скопировали или импортировали (можно задавать и собственные категории).

| Элемент | Что делает |
| --- | --- |
| **Новый шаблон** | Открывает редактор для нового шаблона. |
| **Импорт** | Добавляет шаблоны из файла. Встроенные шаблоны, которые уже есть в рабочем пространстве, пропускаются. |
| **Поиск шаблонов сессий…** | Ищет по названиям, описаниям и заголовкам разделов. |
| **Фильтр по категории** | Показывает только выбранные категории. |
| Группа **Закреплено** | Закреплённые шаблоны предлагаются первыми, когда вы начинаете или планируете сессию. Порядок можно менять перетаскиванием. |

Действия в меню карточки шаблона:

| Действие | Что делает |
| --- | --- |
| **Изменить** | Открывает редактор шаблона: название, описание, значок, категория, фиксация участников, разделы, контекст сессии, свои инструкции для ИИ, заметки во время записи, словарь и фокус для базы знаний. |
| **Закрепить** / **Открепить** | Добавляет шаблон в группу **Закреплено** или убирает его оттуда. |
| **Дублировать** | Создаёт копию, которую можно изменять. |
| **Сделать основным** | Делает шаблон тем, с которым начинаются новые сессии. Текущий шаблон по умолчанию отмечен значком **Основной**. Пока вы его не поменяете, шаблон по умолчанию — «Встреча». Недоступно для выключенных шаблонов. |
| **Экспорт…** | Сохраняет шаблон как файл Markdown. |
| **Восстановить исходный** | Заменяет ваши изменения исходным встроенным шаблоном. Уже существующие сессии сохраняют версию, с которой они были созданы. |
| **Удалить** | Удаляет созданный вами шаблон. Завершённые сессии сохраняют свои итоги. |
| **Создать шаблон заметки из заголовков** | Создаёт новый шаблон заметки с заголовками разделов этого шаблона. |

## Разделы итогов

На этой вкладке перечислены все разделы итогов, сгруппированные по шаблонам сессий, к которым они относятся, чтобы разделы можно было настраивать, не открывая каждый шаблон. В каждой группе также показаны **Контекст сессии** шаблона и, если они заданы, его **Свои инструкции для ИИ**.

| Элемент | Что делает |
| --- | --- |
| **Поиск разделов** | Ищет разделы по заголовку, инструкциям или названию шаблона. |
| **Фильтр по категории** | Показывает только шаблоны из выбранных категорий. |
| Значок перетаскивания | Меняет порядок разделов в шаблоне. Итоги пишутся в этом порядке. |
| **Добавить раздел** (меню шаблона) | Добавляет раздел с заголовком и инструкциями. В шаблоне может быть до 10 разделов. |
| **Добавить свои инструкции для ИИ** (меню шаблона) | Добавляет дополнительные инструкции для итогов целиком. |
| **Восстановить исходный** (меню шаблона) | Восстанавливает весь встроенный шаблон. |
| **Изменить**, **Включить раздел** / **Отключить раздел**, **Восстановить раздел**, **Удалить раздел** (меню раздела) | Изменяют, выключают, восстанавливают или удаляют отдельный раздел. |

Заголовок раздела ограничен 80 символами, а инструкции раздела — 500.

## Шаблоны заметок

Шаблоны заметок дают новой заметке готовую структуру из заголовков и подсказок по содержанию. В TalkBar 44 встроенных шаблона заметок, сгруппированных по категориям: **Общие**, **Продажи**, **Успех клиентов**, **Продукт**, **Разработка**, **Найм**, **Руководство**, **Команда** и **Личное и обучение**. Как ими пользоваться, описано в разделе [Заметки](/chats-and-notes/notes).

| Элемент | Что делает |
| --- | --- |
| **Новый шаблон** | Создаёт шаблон заметки. |
| **Импорт** | Добавляет шаблоны заметок из файла. |
| **Поиск шаблонов заметок…** / **Фильтр по категории** | Сужают список. |
| Группа **Закреплено** | Закреплённые шаблоны предлагаются первыми, когда вы пишете заметку. |
| **Изменить**, **Дублировать**, **Закрепить** / **Открепить**, **Экспорт**, **Восстановить исходный**, **Удалить** (меню карточки) | Стандартные действия, описанные в разделе [Общие элементы управления](#общие-элементы-управления). Удаление шаблона заметки не меняет уже созданные заметки. |

Выключенный шаблон заметки не показывается при выборе шаблона для новой заметки, но остаётся доступен здесь.

## Навыки

Навыки — это готовые ИИ-промпты для сессий, заметок и чатов, например **Составить повестку** или черновик письма после встречи. В TalkBar 24 встроенных навыка, сгруппированных так: **Перед сессией**, **Во время сессии**, **После сессии**, **По нескольким сессиям** и **Текст и редактура**.

::screenshot{src="/screenshots/settings/templates-skills.png" alt="Вкладка «Настройки → Шаблоны и навыки» с открытой внутренней вкладкой «Навыки»: кнопки «Новый навык» и «Импорт», поле поиска и фильтр по группе, группа «Закреплено» и карточки навыков" caption="Навыки"}
::

| Элемент | Что делает |
| --- | --- |
| **Новый навык** | Открывает редактор навыка: название, описание, значок, группа и **Инструкции для ИИ / промпт**. |
| **Импорт** | Добавляет навыки из файла. |
| **Поиск навыков…** / **Фильтр навыков по группе** | Сужают список. |
| Группа **Закреплено** | Ваши основные навыки, которые всегда наверху. |
| **Изменить**, **Дублировать**, **Закрепить** / **Открепить**, **Экспорт**, **Восстановить исходный**, **Удалить** (меню карточки) | Стандартные действия, описанные в разделе [Общие элементы управления](#общие-элементы-управления). Копия при дублировании сразу открывается в редакторе. |

## База знаний

Навыки для базы знаний подсказывают ИИ, что искать, когда он просматривает документ и готовит черновики карточек знаний. В TalkBar 14 встроенных навыков для базы знаний, сгруппированных так: **Главное**, **Команда**, **Клиенты и сделки**, **Проекты и сроки** и **Подготовка к встрече**. Как их используют при поиске знаний, описано в разделе [Проверка и поиск знаний](/knowledge/review-and-scans).

| Элемент | Что делает |
| --- | --- |
| **Новый навык для базы знаний** | Создаёт навык для базы знаний. |
| **Импорт** | Добавляет навыки для базы знаний из файла. |
| **Поиск навыков для базы знаний…** / **Фильтр по категории** | Сужают список. |
| Группа **По умолчанию** | До 3 навыков, которые заранее выбраны при каждом поиске знаний в документе. Используйте пункты **По умолчанию** или **Убрать из выбранных** в меню карточки. |
| **Изменить**, **Дублировать**, **Экспорт**, **Восстановить исходный**, **Удалить** (меню карточки) | Стандартные действия, описанные в разделе [Общие элементы управления](#общие-элементы-управления). |

В новых рабочих пространствах по умолчанию выбраны три навыка: **Факты и цифры**, **Решения и обязательства** и **Риски и вопросы**.
