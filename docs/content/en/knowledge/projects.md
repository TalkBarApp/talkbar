A **project** groups everything about one piece of work, such as a client, a deal, a product or a hire: its sessions, documents, memory cards, people, companies and action items. Projects are optional. You can use TalkBar without them.

## The Projects page

Click **Projects** in the sidebar. Your projects also appear under it in the sidebar, so you can jump to one directly.

| Control | What it does |
| --- | --- |
| **New project** | Creates a project. |
| **Manage** | Opens **Settings → Projects**. See [Projects, topics and keywords settings](/settings/projects-and-topics). |
| **Group by company** / **No grouping** | Groups projects by the company they are linked to. |
| Pin | **Pin project** keeps a project at the top and in the sidebar. |

## Create a project

Click **New project** and fill in:

| Field | What it does |
| --- | --- |
| Icon and color | How the project looks in the sidebar and lists. |
| **Name** | The project name. |
| **Type** | Client, Engagement, Recurring, Internal, Personal, Research, Product, Sales, Hiring, Education, Event or Support. |
| Logo | An image shown on the project page. |
| **Organization** | The company the project is for. |
| **Default session template** | The template new sessions in this project start with. |
| **Links** | Links to docs, boards or repos the project lives in. |
| **Description** | What the project is about. |

Click **Create project**. Use **Edit** on the project page to change these later. Click the project name on its page to rename it.

## Project limits per plan

Your plan sets how many projects you can have in each workspace. Projects in Trash don't count.

| Plan | Projects per workspace |
| --- | --- |
| Free | 1 |
| Personal | 1 |
| Plus | Unlimited |
| Pro | Unlimited |
| Business | Unlimited |

When you reach the limit, TalkBar shows your plan limits instead of creating a project. See [Plans and license](/data/plans-and-license).

## The project page

The top of a project page shows its name, type, description and links, and any upcoming scheduled sessions. The buttons are:

| Button | What it does |
| --- | --- |
| **Export** | Exports the project's sessions. See [Exports](/sharing/exports). |
| **Edit** | Changes the project's details. |
| **Add** | **Move sessions** into the project, or add an **Action item**, **Knowledge card**, **Scan for cards**, **Document**, **Person** or **Company**. |
| **New session** | Starts recording a session filed in this project. |

### Project tabs

| Tab | What it shows |
| --- | --- |
| **Overview** | Pinned and recent sessions, pinned memory cards, and open action items with due dates. |
| **Action items** | Action items, decisions and questions from all of the project's sessions, plus items added to the project itself. See [Action items](/knowledge/action-items). |
| **Sessions** | The project's sessions. Switch between **All** and **Pinned**, filter by topic or keyword, and sort by **Recently updated**, **Session date** or **Title**. |
| **Memory cards** | Cards filed in the project. See [Knowledge cards](/knowledge/knowledge-cards). |
| **Documents** | Documents filed in the project. See [Documents](/knowledge/documents). |
| **People** | People added to the project and the participants of its sessions. |
| **Companies** | Companies added to the project, plus the companies of its people and session participants. |
| **Review** | Knowledge suggestions from the project's sessions and documents. See [Review and scans](/knowledge/review-and-scans). |

The Memory cards, Documents, People, Companies and Review tabs work like the matching tabs in **Knowledge**, limited to this project.

## File things in a project

| Item | How to file it |
| --- | --- |
| A new session | Pick the project when you start the session, or click **New session** on the project page. |
| An existing session | On the project page, **Add** → **Move sessions**. Or set the project in the session's details. |
| A memory card | Choose the project when you write the card, or use **Move** → **Project** on the card. |
| A document | Pick the project under **File into** when you import, or use **Move** on the document. |
| A person or company | **Add to** → **Project** on their card. |
| A note | Link the note to the project from the note's links. See [Notes](/chats-and-notes/notes). |

When you move sessions, you can tick **Also move memory cards from this session** so their cards follow them.

A session series can also be filed under a project. See [Series](/sessions/series).

## Chat about a project

In a chat, open **Answer using** and choose **Project only** to get answers from one project's sessions, notes, documents and cards. See [Ask TalkBar](/chats-and-notes/ask-talkbar).

## Move a project to Trash

From a project's menu (on the Projects page or in **Settings → Projects**), choose **Move to Trash**. The project disappears from pickers and the sidebar. Its sessions, documents and memories stay until you delete the project permanently from **Deleted projects** in **Settings → Projects**. Published session links stay live.

From **Deleted projects** you can **Restore** a project or delete it permanently. A permanent delete lets you choose **Delete everything** or **Keep contents**. See [Projects, topics and keywords settings](/settings/projects-and-topics#deleted-projects).
