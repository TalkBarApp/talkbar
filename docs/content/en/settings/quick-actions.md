The Quick Actions button is the round button in the bottom-right corner of the TalkBar window. It opens a short menu of shortcuts and back and forward buttons. **Settings → Quick Actions** controls whether the button appears and which shortcuts it holds.

For a tour of the main window, see [Getting around](/getting-started/getting-around).

::screenshot{src="/screenshots/settings/quick-actions-tab.png" alt="Settings → Quick Actions tab with Enable Quick Actions turned on and the Menu items list showing the default five shortcuts (Home, New session, Sessions, Chat, Settings) with drag handles and remove buttons" caption="Settings → Quick Actions"}
::

## Enable Quick Actions

| Setting | What it does | Default |
| --- | --- | --- |
| **Enable Quick Actions** | Shows the Quick Actions button on every page. The button is never shown on the recording screen or the session setup screen. | On |

When this is off, the **Menu items** list is marked **Disabled** and you can't change it until you turn the button back on.

::callout{icon="i-heroicons-light-bulb" color="primary"}
The gear icon at the top of the open Quick Actions menu brings you straight to this tab.
::

## Menu items

**Menu items** is the list of shortcuts in the floating menu, in the order they appear.

| Control | What it does |
| --- | --- |
| **Add Action** | Opens **Choose a shortcut:** with a search box and every shortcut not yet in the menu. Click one to add it to the end of the list. The button is unavailable once every shortcut is in the menu. |
| Drag handle | Drag a row up or down to change the order. |
| Remove (trash) | Removes the shortcut from the menu after you confirm with **Remove shortcut**. You can add it back later. |

### Available shortcuts

| Shortcut | What it opens | In the menu by default |
| --- | --- | --- |
| **Home** | The Home dashboard. | Yes |
| **New session** | The new session dialog. | Yes |
| **Recording** | The recording screen. After a session has ended, this item is named **Last session**. | No |
| **Sessions** | The session list. | Yes |
| **Calendar** | Upcoming sessions on a calendar. | No |
| **Chats** | The chat list. | No |
| **Knowledge** | Knowledge cards. | No |
| **Notes** | The note list. | No |
| **Documents** | Imported documents. | No |
| **Projects** | The project list. | No |
| **Chat** | Opens the chat panel ("Ask TalkBar") on the current page. | Yes |
| **Settings** | Settings. | Yes |

The default menu is **Home**, **New session**, **Sessions**, **Chat** and **Settings**, in that order.
